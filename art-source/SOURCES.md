# 《向西守望》美术源文件

此工程基于 `feature/frontend-icey` 的 `393f849`。运行时从 `assets/art/` 读取 PNG 与 Dora 图集。本目录保存对应的可编辑文件。

- `sprites.psd` 按角色、道具、场景图块、特效与界面分组。每帧有独立图层，图层名称与 `sprites.clip` 的条目对应。
- `rooms.psd` 的八个场景分别位于独立图层。导出时只打开对应房间的图层，保留 320 × 180 尺寸，按图层名前缀命名。
- `title.psd` 保存 960 × 540 的标题插画源文件。
- `frames.json` 记录 58 张图块在 1024 × 512 图集内的坐标。可把 `sprites.psd` 导出为同尺寸的透明 PNG，替换 `assets/art/sprites.png`。移动图块时同步更新 `sprites.clip` 的坐标。

## 素材来源

本分支新增的场景和像素素材使用 Codex 内置 ImageGen 生成，按游戏规格裁切、校正脚底位置、整理帧并打包。补充动作以本工程生成的基础角色图作为参照。游戏运行时随包读取本地图像。Dora SSR 许可随官方发行包提供。

## 水墨界面贴图与开源字体（`feature/fe-ink-ui`）

- `assets/art/ui_ink.png` + `assets/art/ui_ink.clip`：程序化多鬃毛笔触模拟生成的水墨界面图集（含飞白横/竖笔刷、墨晕面板、卷轴木杆、残边朱砂方印与腰圆引首章、枯笔墨环、墨迹飞溅、玉简体力墨格及宣纸纤维肌理）。
- `assets/font/lxgw-wenkai-medium.ttf`：霞鹜文楷 Lite Medium（[lxgw/LxgwWenKai-Lite](https://github.com/lxgw/LxgwWenKai-Lite) v1.530），按 GB2312 一级字库与项目用字子集化，采用 SIL Open Font License 1.1（见 `assets/font/OFL-LXGW-WenKai.txt`）。
- `assets/font/mashanzheng-calligraphy.ttf`：马善政毛笔楷书（[Google Fonts Ma Shan Zheng](https://github.com/google/fonts/tree/main/ofl/mashanzheng)），按标题/章目/篆印/中文大写数字及常用字子集化，采用 SIL Open Font License 1.1（见 `assets/font/OFL-MaShanZheng.txt`）。

## 明代角色和标题更新

角色帧依据[前端需求与联调验收](https://github.com/hxsx1016/dora-game/blob/4ed1a7f/docs/%E5%AE%88%E6%9C%9B-%E5%89%8D%E7%AB%AF%E9%9C%80%E6%B1%82.md)中的动作和脚底对齐要求制作。服装和阵营的方向参考明代沿海抗倭图像，角色、色彩和故事为游戏原创设计。 [中国国家博物馆《抗倭图》卷](https://www.chnmuseum.cn/zp/zpml/ysp/202012/t20201217_248560.shtml) · [东京大学史料编纂所《倭寇图卷》](https://www.hi.u-tokyo.ac.jp/collection/digitalgallery/wakozukan/static/about/)

内置 ImageGen 生成周戍、小满、倭寇和拾荒者的新图，以及持铳跑动、拉车和扶柜动作。猎犬取现有高分辨率源图重新采样。站姿周戍从 44 px 提到 66 px，小满从 32 px 提到 48 px，倭寇从 42 px 提到 63 px。角色仍以世界坐标中的脚底对齐，图集使用最近邻采样。
