# 《向西守望》前端开发手册

> **历史手册**　本文记录 `feature/watch-level-rework` 阶段的风台交付、二维贴片方案与当时的待接接口。运行现行项目请打开当前工作树根目录，从 [init.lua](../init.lua) 启动（入口源码为 [init.ts](../init.ts)），经品牌序幕进入标题。试玩入口见[项目运行说明](../README.md#运行)，构建步骤见[开发指南](../CONTRIBUTING.md)，小满四房的模型与操控见[现行 3D 场景说明](小满线3D地图-261127.md)和[分端键位](掌机与KTR赛道适配说明.md)。

前端 Agent 从 `hxsx1016/dora-game` 的 `feature/watch-level-rework` 接手 Dora SSR 单机客户端。第一项交付是城门外的一段连续实机画面：小满数到二十，背景从像素城门慢慢展开为低模风台，玩家亲手决定下一步。两条线各约 90 分钟，均从明初温州宁村所出发，走向北塔。[领单与交付记录](https://github.com/hxsx1016/dora-game/issues/8)

## 启动当时的试玩

先读仓库根目录的 [AGENTS.md](../AGENTS.md) 和[开发指南](../CONTRIBUTING.md)。从干净目录接手时使用以下命令。安装并启动 Dora SSR、连接 Web IDE 后，在仓库根目录运行后四条命令。将 `Dora` 替换为本机引擎可执行文件。

```sh
git clone --branch feature/watch-level-rework https://github.com/hxsx1016/dora-game.git
cd dora-game
python3 tools/check-repo.py
Dora cli ts install -p .
Dora cli build -p . --lang ts
Dora cli run -p . --entry init.lua
```

从标题菜单进入章节选择可以单独排演序章、城门和北塔。正式验收再从序章走到结局。按暂停键检查镜头与字幕冻结，恢复后继续观察同一拍。

## 第一项交付：风台

台词定稿为「小满，慢慢数到二十。哥要是还没出来，你就往北塔走。」风台在 `room.key === "gate" && phase === "gate-count"` 时读取 `countTick`。以 `gateCountAtTick(countTick)` 取当前数，以 `min(countTick / GATE_COUNT_END, 1)` 取转景进度。每秒 60 个模拟拍。配音按数字变化触发，暂停续播沿用当前数字与声音位置。

| 取样拍 | 小满与环境 | 验收重点 |
| --- | --- | --- |
| 0–479 | 一至十稍快，仍望着门。门框侧面开始见光 | 从一开始，袖口退出处和门槛位置接得上送别近景。 |
| 480–1079 | 十一至十七。近处木板渐渐挡住下一层石阶 | 人物始终二维，脚底贴住同一走面。 |
| 1080、1260 | 十八贴耳，十九放轻，中间留呼吸 | 声音、字幕和手势各出现一次。 |
| 1440 | 最后才说二十。低模风台已经完整 | 单人线等待新方向输入。此前一直按住方向键的玩家松开再按即可迈步。 |

**现有入口**已提供 `countTick`、女主迈步和北塔敲门。**待接后端**的项目包括 `storyRoute`、男主长按重逢、背负换弹、武器工台、双通关档案和博物馆。可先用独立样片演示这些镜头。正式版在后端锁定 `soldier` 后播放两下轻叩，握稳后周戍说「我们走吧」。暂停、重试、长按松开都要能恢复到正确姿态。

## 后续领单顺序

1. **袖口三镜与风台双出口。** 柜边露手、城门拉袖、男主风台牵手使用同一道补线。女主线留在低模环境，男主线沿相握的手抬镜回到序章像素风。各交 0、6、12、18、24 秒同机位截图和一段连续样片。[分镜 G01–G06](向西守望-游戏分镜稿.md) · [动画插入表](向西守望-动画插入与演出规划.md)
2. **一条路线先做一个可玩房间。** 女主线做桌下投瓶，暗处看得清鞋尖和落点，砖面与铁盆各有回声。男主线做背负换弹，世界进入慢时，线盘输入保持正常速度。两线默认以环境声、角色视线和动作引导，操作表放暂停菜单。[分线画风](守望-明朝全局美术设定.md) · [前端验收单](向西守望-双线前端交付单.md)
3. **工台、双结局和井底返场。** 工台按实际库存与制作结果更新。北塔同机位各验一份簿页，单人留空，同行写下周戍姓名。双通关后才能在序章寻柜时拾取穿梭器，离馆要回到寻柜任务。[规则与检查点](向西守望-双线后端开发规划.md)

## 验证与提交

每次改 TS 后用 Dora 构建，一并交对应生成的 Lua。引擎项目环境可用 `requireProjectModule('tools.verify-d6')` 验证风台交权，用 `requireProjectModule('tools.verify-integration')` 检查前端集成，用 `requireProjectModule('tools.verify-trial')` 覆盖现有护送试炼。提交前再跑 `python3 tools/check-repo.py` 和 `git diff --cached --check`。

以 Windows x64 键鼠离线版为交付平台。新声音、模型和纹理要随包可读，把新目录加进[打包脚本](../tools/make-windows-pack.sh)，以解压后的离线包检查。交付记录写明分支、提交号、实测系统和分辨率、触发步骤、录屏对应拍号、已验证结果以及等待后端的接口。样片和实机录屏分别标注，便于下一位 Agent 从同一个镜头续做。
