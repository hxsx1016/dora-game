1. **上游锁定基线**：tqym 的 `origin/feature/watch-level-rework`（锁定起点提交 `648ff439318a572a8d45aa46f04738a03f4142e2`）。
2. **前端总集成分支**：`feature/fe-dual-route`（已推送至 `origin/feature/fe-dual-route`）。

   - **允许修改**：`Script/watch/fe/**`、`assets/**`、`tools/make-windows-pack.sh`、`docs/**`。

## 五、核心技术架构约定

### 1. `contract.ts` 双模式前端契约（8 个待接后端字段的唯一入口）
后端目前**已存在** `countTick`、`GATE_COUNT_END = 1440`、`gateCountAtTick(tick)`、`phase`（`prologue-wait`/`prologue-give`/`gate-count`/`gate-walk`/`tower-knock`/`tower-given`）。
后端**尚未落地**的 8 类字段统一通过 `Script/watch/fe/contract.ts` 适配，做到「后端字段一存在就自动读取真实值，不存在时由前端排演 Mock 状态机驱动」：

1. `storyRoute`: `"undecided" | "child" | "soldier"`（城门 80% 血量锁存结果；默认 3 血时 2/3 → `child`，3/3 → `soldier`）
2. `countElapsedTicks` / `countDurationTicks`：兼容映射后端 `countTick`（若后端后续改名 `countElapsedTicks`，此处自动兼容读取）与 `GATE_COUNT_END`（1440）
3. `gateHoldProgress`: `0..1`（男主线风台 0.6s 长按牵手进度、松手退回标志、已牵手锁定标志）
4. `backCarry`: `{ active: boolean; handInHand: boolean; crouchedMount: boolean; atBench: boolean }`（牵手/背负/工台放下态）
5. `timeScale`: `number`（常规 `1`，换弹慢时约 `0.25`；世界与角色/粒子动画吃 `dt * timeScale`，3×3 线盘与光标永远吃全速 `dt`）
6. `reloadSession`: `{ active: boolean; firstTime: boolean; elapsed: number; duration: number; path: number[]; nextEffect: "normal" | "knockback" | "echo" | "light"; invalidFlash: number }`
7. `craftState`: `{ atBench: boolean; firstCraftDone: boolean; materials: Record<string, number>; recipes: CraftRecipeView[]; equippedWeapon: string }`
8. `archiveState` & `museumState`: `{ childCleared: boolean; soldierCleared: boolean; artifactOwned: boolean; museumPhase: "locked" | "well_open" | "well_reflect" | "hall_walk" | "lamp_turn" | "return_cabinet" | "done"; museumSeen: boolean }`

> **对 tqym 的零痛对接承诺**：未来后端任意字段上线，只需改 `Script/watch/fe/contract.ts` 里的读取适配函数，所有前端场景与 UI 零改动自动接入真实玩法。

### 2. 低模 3D 渲染路线（程序化 2.5D 透视低模）
- 为满足 2 天工期、60fps 离线包稳定运行、且**锁死「小满脚底 + 门槛」双对齐点**及 2D 碰撞落点 0 误差，采用**程序化 2.5D 透视低模投影**（`Script/watch/fe/renderer/lowpoly.ts`）：
  - 基于 `CameraDirector` 的世界坐标与视口比例，按 `morph ∈ [0, 1]` 连续拉出墙体厚度、前景遮挡木板/桌腿、阶梯纵深面、体块阴影与体积雾；
  - `morph = 0` 与序章正交像素风无缝重合；`morph = 1` 呈现《小小梦魇》第一作尺度、高反差侧光、压迫前景遮挡的立体低模风；
  - 所有角色始终保持本作 2D 精灵与动作，脚底加接触影贴住同一走面。

### 3. 全程不变的 5 条硬性验收红线
1. **默认低提示 / 零引导**：默认关闭任务箭头、目标清单、就近按键浮签、自动解谜、超时催促；操作说明与「按键辅助」开关统一放进暂停菜单供玩家主动开启。
2. **同一道补线袖口贯通四镜**：`P03` 擦碎瓷、`P05` 城门拉袖、`G05` 风台重逢、`E02` 博物馆回柜使用同一套补线袖口，必须保证观众在周戍露脸前仅凭袖口就能认出他。
3. **明朝美术红线与物件连贯**：背景锁定明初温州宁村所（参考《南都繁会图》《明人画出警图》），**严禁清式顶戴/长辫、近代军帽、西式板甲、仙侠光效、工业路灯、现代步枪/弹壳/探照灯**；板车旧红布固定在车身左端，绝不随小满转向翻面。
4. **静音与灰度可读**：关 HUD、关声音、转灰度仍能分辨守卒/孩子、举枪/挡下（木屑或砖灰）/受击（缩肩）、硬砖/软土、空行/满行。
5. **暂停/重试/读档无污染**：暂停必须冻结镜头、字幕、计数、音频位置与慢时；长按中途松开可重试；切房/重试/读档清干净旧声圈、旧准星与未播事件。

## 六、通用合流与提交 SOP（每条分支 & M0/M1/M2 共用）

1. **开分支前**（在各自工作区，切勿在主目录 `_anchor` 操作）：
   ```sh
   git fetch origin --prune
   git worktree add ~/dev/.wt/2026gamejam/<slug> -b feature/<slug> --no-track origin/feature/fe-dual-route
   ```
2. **提交前必跑验证**：
   - 修改 `.ts` 后必须在 Dora SSR 中执行 `Dora cli build -p . --lang ts`，确认对应 `.lua` 已更新；
   - 运行 `python3 tools/check-repo.py` 与 `git diff --cached --check`；
   - 确认 `git diff --name-only origin/feature/watch-level-rework` **不含任何后端核心文件改动**；
   - Dora 引擎内运行 `requireProjectModule('tools.verify-d6')`、`verify-integration`、`verify-trial` 均零回归。
3. **合回总分支（M0 / M1 / M2）**：
   - 在 `feature/fe-dual-route` 工作区依次合并目标子分支（优先 `--no-ff` 保留清晰阶段脉络或 Squash 整理），解决极少数注册接线处（如有）后重新执行一次 Dora 全量构建并复跑 `check-repo.py` 与回归脚本，推送 `git push -u origin feature/fe-dual-route`。
