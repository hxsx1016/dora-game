## 2. B2a：粮棚取材与第三段工台

### 2.1 房间链

`escort1 → escort2（粮棚）→ escort3（工台）→ escort4（山道四）→ escort5（山道五）→ tower`

- `ESCORT2_ROOM`：棚下 `e2_wood_a`（x=380）、粮袋后 `e2_bell`（x=560）、棚架后 `e2_wood_b`（x=820），三件都在地面，走过即入包。
- `ESCORT3_ROOM`：工台 `e3_bench`（x=560–680，高 44，可站台面），试射薄掩体 `e3_cover`（x=700–756，高 52，可跳），两个靶（x=820/940，`kind:"target"`，被打倒后 36 拍复位）。
- 每个护送房 `campaign.reloadPuzzle=true`；`campaign.goal="reach_exit"`，出口前留 40px 通行，尾墙不再压住 `exitX`。

### 2.2 复现步骤

1. 从 `init.lua` 标题「新的旅程」开始，走到城门守满（或使用回放里的守点快进）→ 送别 → 高石阶背起 → `escort1` 出口。
2. 进入 `escort2`：依次走过 380/560/820 三处，拾到木×2、铃×1。
3. 到 `escort3` 工台，按 E 打开面板：小满被放下、面板列出两张配方。
   - 引路灯铳：木×2，效果 `light`。
   - 回声铳：木×1 + 铃×1，效果 `echo`。
4. 同一制前检查点分别做两件：`craftAtBench("guide_lantern_gun", req-1)` 与 `craftAtBench("echo_gun", req-2)`。材料只够一件，第二件被拒（`benchRejected`）。
5. 按 Q 装备已做武器，再按 E 或 Esc 收起面板；关面板后重新背起小满，走向出口。

- 工台面板打开时世界冻结、玩家不能移动；面板内按 E 或 Esc 收起，随后 `carryOn=true` 恢复背负。

## 3. B2b：第四、五段与北塔团圆

### 3.1 山道四

- `ESCORT4_ROOM`：地面连续 0–1400；断口 `900–960` 高 36（可跳），`arch` 同位置高 36；塌方 380–460 高 40。
- 边走边换弹：移动中按 R（或开火后自动）开盘，`reloadOpen` 期间世界 1/4 速，仍可躲滚石；`jump` 触发滚身（`rollT=0.35`，8 拍推进约 37px）。
- 快速脱身：滚身结束立即继续走，不打断装填。

### 3.2 山道五

- `ESCORT5_ROOM`：塌墙 320–416 高 44、石台 700–860 高 36（可跳）、门柱 1050、塔前壁 1370–1400；带武器到塔门 `exitX=1320`。
- 出门后 `escort5` 段结算一次（`segmentDone`），`escortDone=true`，`requestRoom("tower")`。

### 3.3 北塔结局

`stepTower` 按 `storyRoute` 分两条，共用同一塔场景与敲门动作：

| | 敲门 | 登记簿第一行 | 第二行 | 结局 | 记档 |
| --- | --- | --- | --- | --- | --- |
| 团圆线 | 周戍两下 | 小满 | 周戍 | `reunion` | `soldierCleared` |
| 单人线 | 小满两下 | 小满 | 留白 | `lamp` | `childCleared` |

- 姓名由后端 `endingLines` 给出（`["小满","周戍"]` / `["小满",""]`），`endingReached` 一并带出。
- 结局**不再发放神器**：`archive.artifactOwned` 只反映已有档案，不在落幕时置真。井口主动拾取与跨周目持久化留 C 单。
- 试炼模式（`run.trial!==undefined`）不写结局、不发 `endingReached`。

### 3.4 正式来源与通关资格

- `RunSource = "official" | "chapter" | "debug" | "trial"`，写到 `run.source`。
- 标题「新的旅程」→ `enterPlayRoom(0,"official",true)`；章节预览 → `enterPlayRoom(idx,"chapter")`；数字快跳/调试钩子 → `"debug"`；试炼 → `"trial"`。
- 结局落幕时 `official = run.source==="official" && story.settled && storyRoute!=="" && played`：
  - 男主线 `played = segments["escort5"]===true`；
  - 女主线 `played = countTick>=1440`。
- 只有 `official` 才写 `childCleared`/`soldierCleared`；章节直达与调试构造可以看演出，但不记通关。
- `endingReached` 带 `official`、`source`、`lines` 三个字段，前端可直接区分预览与正式。

### 3.5 失败与检查点规则

- 男主线五段战斗中阵亡：`restartEscortFromDeath()` 回 `escort1`，清本局材料、改制、武器、已拾取物、分段完成、检查点快照与背负；`hp` 回满，保留 `storyRoute=soldier`、过门背景与跨局档案。事件 `campaignFailed{reset:true,to:"escort1"}`。
- 检查点主动重试（R 或暂停菜单「重试」）仍回本段快照：`story.cp` 记录 `{id,wood,bell,scrap,wedge,ammo,shield,pass,quickbelt,crafted,equipped,carry}`，`applyCheckpointSnap` 按 id 恢复。
- 两者区别写在代码入口：`campaignFailed` 只在 `storyRoute==="soldier" && isEscortRoom()` 时回入口；`ensurePlay({checkpoint})` 走快照。

## 7. 前端可直接使用的字段与事件

- 路线与背包：`storyRoute`、`run.source`、`inventory{wood,bell,...}`。
- 段出口：`segmentDone{segment,next}`、`run.story.segments`。
