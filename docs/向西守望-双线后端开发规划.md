# 《向西守望》双线后端开发规划

两条路线分别从序章叫醒计时，到各自结局落幕为止。**女主线约 90 分钟，男主线约 90 分钟**。共同序章在两次首通中各计 30 分钟，其中包含城门外完整的 100 秒。井底彩蛋在双通关后另行计时。

## 每条路线的 90 分钟

| 局内时段 | 小满单人线 | 周戍与小满同行线 |
| --- | --- | --- |
| 0–10 分 | 小满第一人称醒来，透过墙影目睹家中遇袭，限时躲进厨柜。哥哥周戍循着小手找到她，兄妹在井庭墙后看清正街 | 同一段可玩序章 |
| 10–20 分 | 借布行窗板过街，在军粮棚找石槽与门闩连杆，一人先过再接另一人 | 同一段护送 |
| 20–30 分 | 开绞盘、追兵迫近、拉袖送别、落闩。小满在门外数满 100 秒，玩家主动迈步 | 同一段送别 |
| 30–45 分 | 栈台拉开红布检修车，从阶下绕出城。一段家庭回忆教玩家认出车柄上的补丁 | 周戍从检修侧道追上小满，背起她。第一段护送学走位与直连换弹，第二段学在两种连法间作选择 |
| 45–65 分 | 空村从桌下读鞋底朝向，用陶瓶敲砖面或铁盆引开拾荒者，再从暗渠穿过原先的巡线路径 | 粮棚岔路取得素材，抵达第三段安全工台，自选制作第一件武器，再回到房间试用两种连线效果 |
| 65–82 分 | 密林先听枯枝和犬步，再选树根窄洞或旧渠。汇流到溪湾，玩家第一次从水里看到塔灯 | 第四、五段沿山道护送。让玩家在慢时换弹、快走脱身、保留材料之间作选择，用自己做的武器走到塔前 |
| 82–90 分 | 小满叩两下等两声回应，交针套与纸条。守卒记下她的名字，下一行留白，依她所请把灯放到西窗 | 兄妹共同叩门。守卒写完小满的名字，周戍自己答出姓名。第二行写满，两人一同看向西窗，达成团圆结局 |

分别邀请至少三位首玩者走每条路线，记录从叫醒到片尾的完整用时，扣除暂停，保留数数、连线、制作、过场和实际重试时间，并单记每段重试。两条线的首通中位数各以 85–95 分钟试调，相差目标为 5 分钟以内。过短先补有选择的关卡段，过长先看失败和折返集中在哪一房。

## 城门的 100 秒与生死判定

沿用 `clock.ts` 的 60 拍时钟。实现时把 `play.ts` 的 1440 拍数数段改为 6000 拍。门落闩时记第 0 拍，传出 `countElapsedTicks` 与 `sceneBlend = min(countElapsedTicks / 6000, 1)`。两条路线共用同一视角，小满保持二维。前 25 秒先让门框侧面显深度，中间 50 秒让墙、风台和远山依次展开，最后 25 秒由西光投出完整空间阴影。第 6000 拍时低模背景已成形，第一步只交还移动。暂停冻结进度，续读恢复同一拍，按住方向键须先松开再按。

小满过门前周戍阵亡，回城门检查点。小满安全后，结算殿后最后一拍伤害，锁存跨房继承的 `hpAtGate` 与 `maxHpAtGate`。剩余血量低于 80% 时周戍殿后战死，进入女主单人线。`100 * hpAtGate >= 80 * maxHpAtGate`（上限为正）时他存活，进入男主线。演出与读档都只读取该结果。默认 3 格血时，2/3 战死，3/3 生还，扩容后仍按比例判断。

## 小满单人线

小满视角从城门风台进入低模空间，女主线所有非角色美术对齐《小小梦魇》，人物保持本作的二维造型。男主线在风台第一步之后切回序章像素风，背负、战斗、工台及团圆均沿用序章表现。具体镜头见[全局美术设定](守望-明朝全局美术设定.md)。

两线默认由玩家观察环境，自主试操作。关卡状态向前端提供声源、动作、碰撞与结果反馈，默认关闭任务箭头、目标清单、近物按键浮签和自动解谜提示。操作表和按键辅助由玩家在暂停菜单主动打开。数满后的停顿、换弹连线和井底彩蛋均采用这套约定。

参考《小小梦魇》的儿童尺度、环境叙事和观察后行动的节奏，用本作自己的材质和空间组织谜题。以空村为样段，先在桌布下听脚步，再从垂布的缺口看到鞋底停在铁盆旁，最后让玩家选落点引人转身。同一张桌子既是遮蔽也是观察点。威胁集中在短追逐，安全段留给拖车、回忆和辨路。四房复用现有碰撞、听觉与检查点，前端用低模几何对齐走面和可投落点。

## 男主线的协作战斗与制作

复用集成分支 `feature/watch-level-rework@a49eb4d` 的五段护送试炼。`run.ts` 已有种子、三选一天赋、材料和局内血量，`play.ts` 已有装填、制楔和固定拍战斗。继续使用现有 Dora SSR 前端与 TS → Lua 打包。已选定的 [rotLove 固定版本](https://github.com/paulofmandown/rotLove/tree/4e0d9bfcb5bbcd47bc9ac0b93acf17a62f33b70f) 可供生成岔路时取用，接入时先做 Dora 离线验证并保留上游许可。

| 玩家操作 | 后端规则（首轮试调） | 可观察的结果 |
| --- | --- | --- |
| 周戍背着小满移动或转身 | 同一移动主体，朝向决定背侧锚点。进安全工台可放下她，出站重新背起 | 小满始终在周戍身后，换向时跟随，狭道和追逐只判一套碰撞 |
| 请求换弹 | 小满接手，出现 3×3 线盘。试调 4 秒作答，世界以正常速度的 1/4 推进，光标与作答时钟全速。暂停冻结两者，恢复时延续当前路径 | 玩家能看清迫近的威胁，有时间决定这一次的效果 |
| 从起点拖到终点 | 只连相邻点，途中经过一种符号。直连为推退，经过铃纹为回声诱导，经过灯纹为照亮遮蔽。符号和预览都取自同一映射。无效路径可重画，超时给普通效果 | 下一次射击只消费一次所选效果，然后回普通。相同输入与种子得到相同结果 |
| 中期抵达安全工台 | 第三段必有工作台和足够首制材料。用局内素材选择武器方案，例如两枚木纹筹制作「引路灯铳」，或一枚木纹筹加一枚铃纹筹制作「回声铳」。每种方案分别增强灯纹或铃纹效果 | 确认时一次扣料、入包并允许装备。库存不足显示缺项，取消保留材料。读档和重复确认只产生一件 |

结局与路线存入 `storyRoute`，与已有房内岔路 `RunState.route` 分开。检查点保存同伴是否在背上、武器、库存、当前换弹和种子状态。肉鸽失败从男主线入口重新开局，保留本档已获得的通关记录。

## 双通关后的井底彩蛋

1. 同一玩家档案分别完成留灯与团圆，持久化 `childCleared`、`soldierCleared`。任一顺序均可。只在正式剧情结局落幕时写入，调试直达和局内重试保持原记录。
2. 双标记齐全后，重玩序章，在**周戍进屋寻找小满、尚未靠柜触发特写**的窗口，玩家可以循滴水声，经侧灶、后院深入小满家。原来的寻找路线仍可照常走。旧井里映着一盏此时不该亮的白灯，互动取出彩蛋武器「时间穿梭器」。
3. 穿梭器的首次使用把周戍送到现代抗日主题博物馆。采用虚构展厅，入口字幕交代现代时间与纪念主题。可走到玻璃柜前收起武器，听见一个孩子的脚步。末厅由玩家把一盏灯转向西窗，窗上映出井庭，两短叩带他回到柜边。建议只留一句原创台词「小满，外头天亮了。」明初兄妹与近现代展陈通过记忆与守望呼应。
4. 以 `artifactOwned`、`museumPhase`、`museumSeen` 分别记录拾取、访馆位置和完成状态。中途退出可从展厅继续，离馆恢复找小满的任务，回井复查不会重复发奖。重玩男主线可装备穿梭器，拟以短暂重现角色上一段移动残影作彩蛋效果。第三次返场另计约 8–12 分钟。
