# 《向西守望》全局玩法机制设计书

**用途：给玩法实施 Agent 的系统设计，不是关卡案。** 不依赖人物名、房间名、章节顺序或剧情触发。只要有一个可控角色、一个威胁和一个可交互物，就应该能验证这里的核心规则。本文不表示功能已实现。

**核心提案：让攻击改变局势，让物品买到机会，而不是单纯增加伤害。** 同一名持盾敌人可以打碎盾通过、诱出挥击后绕过、保住敌盾再取其掉落，或者根本不与他交手。四种选择在受伤风险、消耗、用时和剩下的世界状态上应有实际区别。若最后都是站桩点射最快、最安全、收益最高，哪怕判定全对，游戏性仍未过关。

**范围约定**：P0 是必须一起交付的基础规则；P1 是基础成立后才值得试的变体；“试调”是首轮实验值，不是已有实现或最终平衡。原《玩法判定与道具制作专项规划》保留作代码交接索引；全局数值出现歧义时，以本文注明的适用对象为准。配套《向西守望-全局机制试玩验收卡.csv》用于执行，不要求搭建任何正式关卡。

## 1. 把游戏性落实为五种决定

| 玩家此刻要决定什么 | 下决定前能读到什么 | 做对赢什么；做错怎样救 |
| --- | --- | --- |
| 现在出手，还是先让出这一次攻击？ | 敌人朝向、预警动作、自己是否已装填、最近一个能隔开敌我的实体 | 出手可取消尚未结算的威胁，但自己进入装填；让开保留下一次出手机会，代价是敌人仍在行动。错过时机可以撤，不靠拼血补救。 |
| 把掩体当保护，还是把它打成通路？ | 永久或可碎材质、裂纹、挡住谁的来向、碎后露出的空间 | 留着可以短停或接同伴；打碎可能让双方都更容易通过，也同时让敌人获得射界。最后一击不穿透，玩家还能看清变化。 |
| 自己先走，还是把一个安全窗口让给同伴？ | 同伴位置、停步原因、下一个可达安全点，以及威胁当前盯着谁 | 自己先走能抢位置，但不能把同伴瞬移过来；先接人花掉一个窗口，换来下一次同时行动。判断错可回接，不重开。 |
| 现在拿这件东西，还是把格位留下？ | 物资用途、两格现状、地面物是否安全可回取 | 换不是销毁。留下、折返、消耗后再拿都有效；不让玩家在危险中被强制弹出的背包遮住预警。 |
| 我是真的被发现，还是只留下了一条线索？ | 转头方向、调查落点、追逐姿态和脱离后的搜寻动作 | 制造声音能改变敌人朝向；遮断视线能使精确追踪退化成搜寻。惊动不等于失败，失误之后还有第二次决定。 |

**深度不靠新增按钮。** 第一轮不用等级、暴击、闪避概率、武器稀有度、饥饿值、体力条或击杀连段。玩家应能用一次已经学会的动作解新问题：一次点射能退敌，也能破障；同一块遮挡既截断射线，也可能让敌人失去视线。增加新系统前，先证明现有动作做不到这个决定。

## 2. 动作语法：能取消什么，承诺了什么

规则按能力而非角色名字绑定。**战斗型**可点射、贴靠、翻滚、用战具；**潜行型**可慢行、蹲行、瞄准投物；**护送对象**有独立身体、感知和安全目标。通用的移动、互动、落点、声音、遮挡都走同一套判定，不为每个模式复制物理规则。

| 动作 | 承诺点 | 允许的取消与代价 |
| --- | --- | --- |
| 点射 | 按下且合法的这一拍定出手；命中与否都开始装填 | 不靠翻滚、切物或交互重置装填。未装好时点击只作一次轻提示，不缓存一发在装好时自动射出。 |
| 翻滚/翻越 | 起步时检查前方是否有可攀边及落脚面；有则翻越，否则翻滚。起步后不把滚动中途改成攀爬 | 翻滚不是通用无敌。能脱离锁定线、避开盾击，但撞向障碍不会穿过去，迎面滚进射线可能受伤。避免“滚得越多，玩得越好”的唯一解。 |
| 贴靠/探身 | 接触判定按移动后的身体边界；按住贴靠改变姿态，不改变墙的位置 | 退出即时恢复普通姿态。P0 不另做“探头键”：玩家从边缘横移露出射线即可开火，也会重新暴露。不能把枪口隔墙投影到另一侧。 |
| 握持/推动 | 正确一侧、同高、可达，才占用双手；成功后才响应持续方向输入 | 松开或有效受伤则脱手，已推动的距离保留；失去握点不能隔空继续推。手忙时不准射击、制物、翻滚或投掷。 |
| 预览/投物 | 按住预览不消耗；松开且有合法初段轨迹才脱手，扣一件 | 脱手前取消无损；脱手后即使投偏也不返还。实际碰撞决定落点，绝不为了帮玩家而吸向最有利目标。 |
| 安抚/制作 | 查询合法对象，再新按确认；开始后双手被占用 | 制作确认前不扣料、完成才换产物。安抚中不可兼做别的交互；施助者倒地则中止。持续按住旧键不能跨状态确认。 |

**操作清晰度是玩法前提。** 一个按键只触发 HUD 当下写的那件事。当前输入代码把 `S/↓` 同时报给向近侧移动与蹲下；实施时应分开这两个意图（建议方向只管纵深、`Ctrl` 专管低姿），保留可重映射。否则“想往近侧走却消除了脚步声”会破坏整个潜行机制。灰盒先验键鼠与同拍互斥，不把调试切换键直接拿来当正式道具键。

## 3. 生命、血量与挽救窗口

**生命是角色还能否行动；HP 是其中一种结算值。** 不让血量同时代表士气、被发现程度、盾面耐久和同伴状态。

| 状态池 | P0 规则 | 明确不发生什么 |
| --- | --- | --- |
| 战斗型生命 | 3 格，普通有效伤害 1。3→2 提示来向；2→1 保留全部操作能力，血格轮廓改变；1→0 当拍倒地。稳定整备点首次补满并保存，普通安全点只提供操作空间。 | 残血不降速、不延长装填、不缩短安抚距离；无自动回血，不奖励反复踩同一点。不能让最需要反制的玩家最没能力反制。 |
| 受伤保护 | 受伤拍记 `t`；`[t,t+42)` 内不再扣 HP，`t+42` 可再受伤；只计算可控模拟拍。 | 不把所有来弹删除，不替同伴免恐惧，不让持续接触按渲染帧扣血。挡下不触发受伤保护。 |
| 护送对象恐惧 | 0–3 格；1–2 格先找可达安全锚，3 格停在当前可站位置。只对处在危险影响内且未被保护的同伴记一次；危险有唯一 ID。近身安抚第 12/36 拍两声反馈，第 36 拍降到 1，第 60 拍恢复跟随。 | 同一次攻击的预警、枪响、命中特效不能收三次恐惧。同伴在实体后而玩家中弹，不能连坐。满恐惧是一个可救的局面，不是失败画面。 |
| 潜行型生命 | 无 HP。声响→调查，目视确认→追逐，有效身体接触→被抓；只有最后一步进入失败。 | 敌人转头不能等价于抓获，投偏不直接读档。不要在不知下一步做什么时只显示一根红条。 |
| 物体与敌人耐久 | 普通敌人身体一次有效命中退出；盾、角色身体、可碎物各记各的耐久。盾碎后仍是能行动的敌人。 | 不给普通敌人偷偷加血撑时长。不用隐形伤害减免维持难度；难来自接敌姿态、站位和出手窗口。 |

**同拍多击的例子**：角色 1 HP，先后有一发被盾挡、一发命中身体。正确结果是盾消失、角色倒地，不是“盾已生效所以本拍无敌”。反过来，先中身体进入倒地，后续攻击不再对该角色生成第二条失败。回放要能指出哪一个结果来自哪一次攻击。

**重试分两本账。** 玩法账回到同一拍快照：背包、地面物、敌人、盾面、临时部署、同伴和机关全部一致。试玩统计账保留失败原因与尝试次数，不能因回退而抹掉难点。残血快照必须有无伤离开办法；若测试者只能靠故意死来补血，应改恢复策略或威胁组合，而非把死亡变成补给操作。

## 4. 战斗：一次出手，四种可能的收益

| 玩家目标 | 出手对象与反馈 | 取舍 |
| --- | --- | --- |
| 消除威胁 | 击中暴露的本体，取消未结算的攻击；身体失衡并退出行动 | 下一段装填时间无法点射。如果对方其实正被墙挡着，这一发未必值得。 |
| 换取移动窗口 | 盾面挡下时给木响、裂纹；P1 试验“首次正面盾击中断其蓄力 12 拍”，只对该次蓄力生效 | 牺牲完整盾的掉落换当下空间。若出现连续射击永久控制，先移除此试验，而不是给全体敌人霸体。 |
| 改变地形 | 同深度射线先碰可碎物就扣耐久；最后一击只打碎，不穿透。下一次攻击读取新通路 | 新开的路线敌人也能用；失去挡弹面是确切代价，不是纯粹开捷径。 |
| 保留资源 | 不射，趁敌方瞄点已锁或收招换纵深；武器仍就绪 | 节省当下的装填空窗，但威胁会再次行动，也不会给掉落。零击败是技法，不是漏做战斗。 |

**统一命中顺序**：过动作合法性 → 将瞄准映射到世界 → 查询有限线段或挥击体积 → 排除错误纵深、高度、来向和被遮挡部分 → 以最近真实交点结算 → 写耐久或生命 → 再发反馈。等距时实体先于盾，盾先于身体，同类以稳定 ID 排序。人物与敌人用同一空间语义，不能“玩家打墙，敌枪穿墙”。软帘可以遮视线而不挡弹；实木挡是否挡弹由材质标记，不由名字或贴图推断。

**首轮时序怎么调，而不是只给一个数字：**

| 参数 | 起点 | 调整时观察什么 |
| --- | --- | --- |
| 点射装填 | 基础 54 拍；装备快装带且出手时贴永久掩体取 36 拍 | 两者相差 18 拍，必须能改变一次合法行动窗口；若不改变任何决定，不再堆百分比，先改窗口或撤战具。 |
| 远程预警/冷却 | 预警 36 拍。当前本地存在 150、240 拍两套冷却；作为**常规／宽窗口**两个参数档复测，不把其中一个误当全局唯一值 | 从锁定瞄点到命中有 0.6 秒。用实际运动量和身体宽度验能否走离；双手占用型任务用宽窗口档试调，不把全游戏改慢。 |
| 近战预警 | 盾击 18、重击 24 拍起测；计时起点是玩家首次能看见方向的动作，不是敌人内部进状态的时刻 | 不看调试线也能指出哪侧可退。玩家在有效拍前离开攻击体积，敌人应打空并完整收招。 |
| 并发威胁 | 初次学习每次最多一个新预警；熟练组合可叠两个，P0 不上三个同时要求不同方向闪避的结算 | 不是简单限制敌人数。同侧两敌共用一个反制是可读组合；两侧同时封死又不给可达安全位，是无解组合。 |

**不奖励故意吃伤的捷径。** 允许高手用血换时间，但不能让“连吃两下硬走”同时是最快、最稳且库存最多的方案。对照录三条：硬闯、等窗、不还击绕行。若硬闯全面占优，先检查威胁是否只作用于主角、同伴是否被传送、交互是否错误地忽略双手占用；不要先提高伤害。

## 5. 敌人/怪物：它知道什么，比它有多少血更重要

每个敌人分三层：**能感知的事实**（看见谁、听见何处）、**当前意图**（调查、准备攻击、追逐）、**结算能力**（此刻能否命中）。例如，听见一个瓶子只能得到落点，不会同时得到投掷者坐标；开始追逐也不代表能隔着高差判定抓获。

| 原型 | 决策与记忆 | 至少两种反制 | 禁止行为 |
| --- | --- | --- | --- |
| 远程压制者 | 看到暴露目标才发起预警，预警锁瞄点；本次落空也要走冷却 | 截断真实射线；离开锁定线；提前命中本体 | 预警结束瞬转瞄向新位置；穿过永久实物；屏外无提示第一击。 |
| 持盾压近者 | 朝向独立于射线。接近→抬盾→结算→收招；起手锁朝向，收招结束才重新追人 | 打盾耗其耐久换正面通行；诱挥后从侧背命中保盾；也可绕过 | 转身速度无限、盾面在背后也有效、前进时卡在够不到又不再靠近的距离。 |
| 破障者 | 锁定一个可达的可碎对象，否则才选人；挥击只在有效拍查一次 | 打断保住挡板；离开让它砸开通路；绕到不在挥击面的一侧 | 已锁物件被抢先打碎，重击自动转移到身后的玩家。 |
| 听觉调查者 | 未确认目标时按实际落点调查；调查结束搜索最后已知点，再返回巡逻 | 强声引其转向；用遮挡绕过；投错后在其未确认前撤出 | 在连续收到声音时逐拍掉头抖动；一被听见就锁定角色位置。 |
| 追踪者 | 巡行→朝声源转向→看见或重新确认才追；失去视线追到最后已知处，找不到则转嗅闻 | 停止制造声响并断视；持续移动甩脱后改变方向；低姿穿过对方不可达的开口 | 蹲下这一动作本身抹除眼前的可见角色；隔着不可达层或封闭碰撞体抓人。 |

**声音与视线的组合规则。** P0 只分静默、轻、响三档，无需连续分贝模拟。低姿慢行在软面为静默；正常走动在硬面为轻；奔过响面和合法投物撞击硬面为响。每类接收者配置轻/响可听距离，可达声路被密闭屏障截断，不拿直线距离代替全部传播。调查目标选优先级最高的有效声源，同级取最近发生者，再按稳定 ID。已目视确认的敌人不因为身后一只响物立刻忘掉眼前目标。玩家必须能在无声播放时从转头和停步读出结果。

**潜行的宽容来自信息，不来自敌人装瞎。** 建议普通调查者从连续可见 18 拍开始确认，短暂露头只朝可疑点转头；失去视线后确认积累逐步衰减而非立刻清零（P0 试值：每不可见拍减 1，最低 0）。确认后追逐用最后可见位置，不再用该积累条。贴脸且同侧无阻挡可立即确认，但仍要实际接触才能抓。关闭预警 UI 后，朝向、锁定和回搜必须能单靠姿态辨认。

## 6. 世界交互：用属性组合，不给每件道具写专属例外

| 属性 | 判定用途 | 能带来的玩法差异 |
| --- | --- | --- |
| `blocksMove / blocksSight / blocksShot` | 独立决定挡身体、挡视线、挡射线；可按高度与纵深占地查询 | 薄布遮视不挡弹，栅隔开身体却可观察，实木能挡弹并可能受损。材质与声音必须让差别可学。 |
| `usableSide / reach / clearance` | 手是否在允许的一侧；手到接触面是否够近；动作终态是否有净空 | 看得见不等于够得着。不能从另一面拉柄、起身穿顶、把盾部署在同伴必经位置。 |
| `durability / acceptsWedge / reinforced` | 完整→受损→破坏；完整且允许加固才收木楔，最多一次 | 2 耐久薄木加固后承受三次普通破坏。裂后不让修回满，防止长时间守着一块道具无限维护。 |
| `noiseSurface / investigationPoint` | 接触材质决定声音档；敌人以可达调查点回应 | 相同投掷操作，落点不同可换方向、换窗口或无声失败。声音从落地处发生，不从鼠标光标发生。 |
| `persistentState / stableId` | 一个对象变更后，运动、视线、射线、同伴寻路和读档都读取同一状态 | 打碎就是全局打碎；不会出现画面已通、同伴仍绕，或读档后只剩一面看不见的墙。 |

**候选选择**：先过滤不合法的目标，再按动作优先级和实际接触距离选一个。如果玩家正对一个不能用的把手，附近却有可用机关，不能让无效提示吞掉有效操作。同伴需要安抚与近处普通机关重叠时，优先安抚；自动拾取不占用 E，也不能使角色停步。两个合法同类目标重叠时，站位/指向改变才切换，避免提示每拍跳动。选择变更后必须有新按边沿才能确认第二个目标。

## 7. 拾取与掉落：管理两个格子，而不是管理一张长清单

**战斗型容量：一格常驻战具、两格各装一件的消耗品。** 没有材料钱包、同类叠堆或背包升级。残盾属消耗品；号牌和快装带才占常驻位。潜行型单独持一件投物；通行凭证等关键物独立管理、不能丢弃、不被普通拾取顶掉。

| 物品 | 使用前提 → 效果 | 设计的取舍与边界 |
| --- | --- | --- |
| 备用弹包 | 正在装填 → 立即结束这一次装填；仍要玩家再次主动按射击 | 买的是第二次出手时机，不是永久加射速。已就绪时不消耗，同拍不能凭一件物资结算两发。 |
| 残盾 | 前方部署足迹合法 → 固定在世界中，挡穿过其盾面的第一发 | 正面防护换掉一个格位；不能护背、不能跟人走、不能堵必要交互面；合法部署后不返还。 |
| 木楔 | 完整、允许加固且尚未加固的物件 → 增加一次普通承击 | 价值取决于未来是否还要利用这个物件。若放弃该通路，这一楔不会凭空换回资源。 |
| 快装带／护送号牌 | 常驻且互斥；前者仅在永久掩体后开火时缩短装填，后者在相邻且可达的安全点发等候／跟随信号 | 一个买个人出手窗口，一个买同伴调度。号牌不是传送或免恐惧，基础跟随与安抚不需要装备。 |
| 废木料 | 占用一个真实格；可在合法工作面制为木楔，或暂时保留 | 未加工不会自动开路。拿走木料意味着眼前的弹包或残盾至少有一种可能带不走。 |

**有意图的掉落，不开盲盒。** 装备在敌人身上就能看见；完整 2/2 的盾手退出才掉残盾，打裂至 1/2 就失去该收益。普通敌人不连续重生供刷物。同一掉落从 `在世界 → 在格中 → 已消费` 只占一种状态；丢下或换装则回到世界，落在实际可达点。角色尚未离开拾取范围不能自动捡回刚丢的物件。满包路过只给一次轻提示，保持地面物，不写“已拾”。

**三种配装用来试，不是固定职业。** `弹包+残盾` 适合主动开路，连续交火强，无法加固；`木楔+残盾` 能为两次移动保留挡面，但没有紧急第二发；`木料+空格` 有现场应变余地，却没有即时保护。与空包作四方对照，记录“实际改变过决定的物品”而非捡了几件。若一个组合在相同威胁下总是更快、更安全、且几乎无消耗，先查物品是否少了触发条件。

## 8. 制作：先证明一件成品值得做，再增加第二张配方

**P0 配方：废木料 ×1 → 木楔 ×1，45 有效拍。** 目的不是教玩家看合成菜单，而是让他决定“现在把一格和一段安全时间换成多一次掩护，还是留着装别的”。要让这个决定成立，确认前应显示结果与适用对象，例如「多挡一次普通破坏；已裂的木件不能加固」。不需要玩家先做错一次才学到边界。

1. **发现**：持料或查看合法工作面即可看到配方、缺料数和成品功能；不弹全屏教程。未持料时仍能查看，不开始计时。
2. **选择**：确认前能退出。工作面可达、角色有对应能力、双手空闲、没有指向工作位置的有效威胁，才允许开始。敌人存在于世界不等于工作面不安全。
3. **加工**：锁输入实例而不提前扣料。走离、取消、受伤、工作面失效或重新进入危险均中止；暂停只冻结。失败原因明确，如「失去遮护」，不笼统写“条件不足”。
4. **交付**：第 45 拍末重验，通过才在原输入格原子替换；两个格都满也能一换一。完成与受伤同拍先处理受伤。长按确认不能连续制作，重试不复制成品。
5. **证明价值**：对同一完整物施加同样三次普通破坏；有楔比无楔多出一次真实的停留或通过机会。如果测试者只看到一个数字从 2 变 3，却不能多完成任何动作，就调攻击间隔和物体用法，不再添加配方掩盖问题。

**P1 唯一优先试验：同一废木料 → 响木 ×1。** 用现有投物与听觉接口，不加新材料栏。它落在硬面产生一次响声、不伤人；软面效果弱，已目视确认的敌人不转移追踪。战斗型须先放下双手占用物，再进入投物预览；不能边瞄枪边瞄投物。它与木楔的区别不是“弱配方/强配方”：一件延长原地安全，一件把未确认敌人的注意力移走。该试验只给有加工能力的控制模式，不改潜行型原有瓶位。**上线条件**：盲测中两种成品都被用于不同意图，并能说出为什么没选另一种；若响木只是替代原有投物或吸引已确认敌人的万能按钮，就撤掉它，保留一张真有用的配方。

**禁止的扩张**：批量制作、制作熟练度、随机品质、耗材修理循环。它们会奖励重复劳动，而这套系统需要奖励判断时机。

## 9. 五个系统相遇时，谁说了算

P0 固定 60 拍。一个模拟拍内按下列顺序提交：控制权与暂停 → 移动/姿态与动作合法性 → 玩家出手/瞬时效果 → 仍有效的敌方结算 → 受伤/恐惧/倒地 → 拾取、加工完成和机关完成 → 进度与快照。多个敌人按稳定 ID；同一次输入只消费一次。有争议的订单必须用双向对照验，不靠画面“看上去差不多”。

| 冲突 | 正确结果 | 这条规则保护了什么玩法 |
| --- | --- | --- |
| 敌人即将出手，同时玩家击中其本体 | 敌人退出，未结算的那一击取消；若只击中普通盾面，P0 不取消已承诺攻击 | 区分真正的打断与视觉上有火花；不让连点盾牌代替走位。 |
| 角色躲入掩体，同时敌弹结算 | 使用移动后的身体与射线；挡下就不扣血；退错侧则仍中 | 救场靠自己的移动，不靠按键本身触发无敌。 |
| 木件被第一发打碎，同时第二发抵达 | 第一发停在木件，第二个独立攻击读取已打开的射界 | 破坏有空间后果，不能靠渲染下一帧才清碰撞。 |
| 角色在地面物上满包，同时使用一个合法消耗品 | 先用再尝试拾取；有空格则只收一件，HUD 能读出“用了什么、收了什么” | 奖励现场腾格；禁止一件物资先被拾取又回到同拍用来支付同一动作。 |
| 同伴受惊与玩家未受伤同时发生 | 两者分别看自己的位置、遮挡和危险 ID | 玩家不能凭自己没掉血推断同伴安全；同伴也不能代替玩家吸收命中。 |
| 制作完成、致命受伤、自动存点同拍 | 倒地优先，制作不提交，不产生新存点；重试读上一个完整快照 | 防止死亡锁档、刷成品、丢失材料三种破坏信任的问题。 |

**回放记录最小字段**：尝试 ID、种子、有效拍、主体与目标稳定 ID、输入边沿、所选动作、结果原因、变更前后值。连续状态供 HUD 读取，瞬时声音/受击/掉落供事件消费；同一渲染帧补跑几步都不能多播一次。调试界面可以显示命中体和听觉范围，正式体验不能以打开调试线为前提。

## 10. 难度、反馈与重玩：改挑战，不暗改规则

- **难度的四个旋钮**：预警读懂所需时间、同时需要关注的意图数、可用遮挡持续多久、一次失误后到下一次决定有多远。先动一个旋钮并保留同种子对照。不要同时提速、加血、减掉落，否则无法知道是什么变难。
- **辅助设计**：可试“延长预警、强化来向、声音转视觉”三个独立选项。不要以自动选最佳道具、自动移动同伴、准星自动穿掩体来代替玩家判断。普通与辅助使用相同命中规则，计时测试标注所用设置。
- **战斗反馈最小词表**：木裂=挡面损伤；砖灰=永久实体挡下；身体失衡+血格变化=真受伤；转头=听到；持续朝向并起步=确认；停在最后可见点张望=丢失目标。每一项都要能在静音或去色其中一种条件下辨认。残血不持续遮盖屏幕边缘的预警。
- **重玩变化只改变局面**：改变可见携带物、初始朝向、可损物状态、两种威胁的组合；不暗改同一动作的命中距离、伤害、听觉语义。先用三组作者配置（保护机会多／诱导机会多／资源少），每组验证空包可解，再谈抽种子。
- **不做永远正确的动作**：全程贴靠若同时免远近攻击，是遮挡判定坏了；蹲行无论站哪里都不被发现，是感知坏了；击败所有敌人若同时最快和最安全，是通行或奖励结构坏了。优先修这些原因，不用隐形倒计时惩罚玩家。

## 11. 怎么证明真的好玩，而不仅是没有报错

第一轮先做无剧情的**机制试验台**：可开关攻击源、设 HP、切材质、放一个可交互物、切同伴/库存、回到同一起点。正式 UI 能打开或关闭，回放能复用固定输入。实施先交付下列四组证据，暂不申请新增怪物、材料或地图资产。

| 试验 | 具体做法 | 通过门槛／不通过怎么办 |
| --- | --- | --- |
| **规则能否预判** | 找 5 名未看策划的人。首次观察后，在盾面／掩体／声音／制作四类结果发生前暂停，请他预测结果和理由；答完继续，不揭晓标准答案诱导下一题 | 首轮目标每类至少 4/5 人能说对关键因果。集中错一类先改姿态、音画或提示；不要先放宽命中盒。此为迭代门槛，不是统计证明。 |
| **策略是否真有区别** | 同一配置、同一起始状态分别跑“直接交火／避战／消耗品辅助”。逐次记有效拍、损血、同伴恐惧峰值、耗材和剩余世界状态；空包单独跑 | 至少两种策略各有一项明确优势；若一条在全部指标都不差、至少一项更好，换两组配置复验。三组都如此就撤或重做弱策略，不靠给它加成就解围。 |
| **失误后是否还可操作** | 人为制造三种不利状态：剩 1 HP、同伴恐惧 3、投物未奏效。观察玩家下一步做什么，不由观察员教操作 | 每种都有不靠读档、不靠掉落的合法恢复线；至少 4/5 人在一次解释机会前能指出一种可尝试的动作。若知道但执行不了，改窗口；若根本想不到，改反馈。 |
| **重复游玩是否学会东西** | 第二次给同配置，不加属性。记录首次主动利用预警、主动放弃物资、失败原因及第二种解法；随后换一组配置，看技巧能否迁移 | “时间更短”不是唯一证据。玩家若能主动描述并再次做出“我让它挥空，所以保下了盾”，说明学会了可迁移的技法；若只记住脚本秒数，不增加内容，先改可读信息。 |

**处理反馈的次序**：先问“你当时以为会发生什么”，再看录像和命中原因。不知道为什么输 → 查可读性；知道却来不及做 → 查控制权、预警和净空；总选一个办法 → 查收益和代价；输了只能重开 → 查补救窗口。这四类问题不要都用“把难度调低”回答。

## 12. 交给实施 Agent 的顺序与停止条件

| 批次 | 写什么 | 何时才往下做 |
| --- | --- | --- |
| ① 判定可信 | 生命状态、动作互斥、统一命中和固定拍仲裁；保留当前两个冷却档的对照 | 配套卡 `HP/ACT/HIT` 通过，静音能区分挡下与受伤。否则不加敌人。 |
| ② 威胁可读 | 一个远程、一个盾面、一类调查/追踪感知；把同伴暴露和安全锚接入 | `AI/ESC` 通过，能靠走位躲击、保盾、诱导或脱离，不能隔层抓取。 |
| ③ 物资有价值 | 真格位、稳定物品 ID、部署与唯一 P0 配方、原子重试 | `INT/INV/CRA/SAV` 通过，实际观察到一次因物资改变动作的决定。只展示配方 UI 不算完成。 |
| ④ 再决定扩展 | 做三组配置、两轮盲测；响木与盾面打断作为两个独立 P1 实验，各有关闭开关 | 附同种子对照与被否决的方案。只要 P0 仍有唯一最优解或失败原因说不清，就不铺 P1。 |

**最终交接物**：规则回放、失败样本、同种子策略对照表、玩家原话及下一轮只改哪个变量。验收卡里的数值都是预期，未运行不得写“通过”。交付目标不是系统数量，而是玩家能说出：“下一次我准备换一种做法”，而且游戏规则真的允许他那样做。
