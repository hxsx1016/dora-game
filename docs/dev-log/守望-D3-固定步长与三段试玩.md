## 二、固定步长

`clock.ts` 只做一件事：把真实帧时长换成整数个 1/60 步。

```ts
advance(frameDt: number, maxSteps = 5): number
// 截到 0.25 秒上限 → while (acc + 1e-9 >= STEP && steps < maxSteps) acc -= STEP
// 超上限时 acc 清零并 dropped += 1，避免追帧滚雪球
```

实测（引擎内 `dora_agent_command`）：

| 用例 | 输入 | 结果 |
| --- | --- | --- |
| 120 Hz 两次回调 | 1/120 + 1/120 | 0 步、1 步 → 合计 1 步 |
| 30 Hz 一次回调 | 1/30 | 2 步 |
| 卡顿帧 | 1.0 秒 | 5 步 + `dropCount=1` |
| 零／负时长 | 0、−1 | 0 步 |

## 三、输入锁存

`Input` 每帧只采样物理键；`beginStep(first)` / `endStep()` 决定边沿何时可用：

- `edge()` 只置位不清零：`held && !was → pressed`，`!held && was → released`。
- 一帧里第一步 `beginStep(true)` 保留采样到的边沿，后续步 `beginStep(false)` 清掉，避免同一次按下被两步各算一次。
- 0 步的那一帧（高刷新率）不清零，边沿留到下一个真正跑的模拟步。

实测：把 `interact.pressed` 置位后跑两步，`knocks` 从 0 变 1 并在第二步保持 1、`pressed` 已清；0 步帧之后 `pressed` 仍为真，下一步消费掉。

## 四、护送与安抚

`Escort` 五态：`follow` → `seekCover` → `sheltered` → （连续三次有效危险）`frozen` → `calming` → `follow`。

- 危险按 `dangerId` 去重：同一个 id 重复派发只返回当前恐惧，不叠加。
- 三个**不同**危险才满格；实测 `applyDanger(1)=1`、再次 1 仍为 1、`(2)=2`、`(3)=3` 并转 `frozen`。
- `frozen` 时小满停在当前脚下、蹲下捂耳；周戍走到 64 单位内点 E 进 `calming`。
- 安抚 60 拍：第 12 拍第一声、第 36 拍第二声且恐惧写回 1、第 60 拍回 `follow`。实测 tick 读数 12 / 36 / 60 全对。
- 周戍在安抚 60 拍内锁移动与交火，只落体。
- 出口：车落窝且 `player.x` 与 `partner.x` 同时落在 `[792,928]` 才 `gateOpen`。实测未落窝 false、落窝两人在 850 true、小满退到 700 false（W03）。

## 五、拉车

两侧共用一套 `stepCart`，差别只在手柄偏移与车轴区间：

| 房间 | 车轴区间 | 手柄 | 抓取条件 | 结果 |
| --- | --- | --- | --- | --- |
| 检查站 | 640 → 768 | 轴 −40 | 距手柄 ≤70 且 `|y − baseY|` ≤40 | 130 步拉到位，`cartDocked=true` |
| 城外 | 304 → 432 | 轴 +40 | 同上 | 150 步拉到位，`cartDocked=true` |

握把期间玩家位移由车带着走（`dir = gripping ? 0 : input.moveX`），不再叠加走位——这是首轮 T-E 失败的原因：人自己走会跑到车前 70 外脱手，车轴只到 656。

- 松开 F/E 所在键即脱手，`gripping=false`；再按 E 且仍在 70 内可重新握住。实测 `mid=346.7` 松手 → `402.8` 再握 → 最终 432 落窝。
- 城外车在**下层**才挡路：`slideX` 对 `y < 44` 的玩家按 `[轴−24, 轴+24]` 回推。车轴 304 时挡 280–328（正堵住拱洞来路），拉到 432 后挡 408–456（已在出口之外）。
- 44 拱洞：站姿 64 走到 290 停住；蹲姿 36 可穿过 304–416 到右沿；洞内站起会被推回洞口外。
- 重试：`new Play(room, { checkpoint })`。洞前重试车回 304；洞后检查点（≥380）重试车在 432 落窝、小满在 390。

## 六、柜台与翻越

检查站的柜台原本是 60 高的实心盒，D3 接跟随才发现它把前半段整条路堵死：周戍没有跳跃，小满跳 51 也上不去，两人都到不了 600 的车。改法是把柜台压到 44，并补两种通过方式：

| 角色 | 方式 | 触发 | 高度 |
| --- | --- | --- | --- |
| 周戍 | 空格改成「翻上去」 | 面前 26 单位内有 `0 < 台面高 ≤ 60` 的盒子 | 340 初速，约 58 高 |
| 小满 | 跟随撞台自动跳 | `slideX` 位移 < 0.4（被挡住）且在地面 | 320 初速，约 51 高 |

平地按空格仍是翻滚，手感不变。实测：周戍走到 225 贴住柜台，空格后落到柜面 y=44，再走可越过到 717；小满自动跳过柜台跟到 452，全程没有卡住。

## 七、村口投瓶

- 瓶架 x=112；走到 56 内点 E 拾瓶。
- 按住 F 累积，松手按固定飞行时间 T=0.62 反解初速，落点跟准星；飞行中画 12 段抛物线预览。
