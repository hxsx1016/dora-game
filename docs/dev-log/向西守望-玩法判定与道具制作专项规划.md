# 《向西守望》玩法判定与道具制作专项规划

2026-11-25｜交给玩法实施 Agent。本文是制作规格，不是已实现清单。与同目录《向西守望-新版一小时关卡策划案.md》配套：关卡案管路线、剧情和时长，本文管玩家做一个动作时，游戏承认什么结果、失败后还留下什么。

**玩家要读懂三件事：这一击为何打中，我站在哪里才能做这件事，我拾到的东西能改变哪一段走法。** 周戍线的代价是受伤和同伴停步；小满线的代价是暴露位置、重找窗口。两条线不用同一根血条。首批只验 S1 十字街至 C2 军粮棚；G2、村庄、森林是第二批，不要把 27 场重制绑在首批交付上。

## 2. 玩家生命与血量：失败是什么，数值怎样算

| 对象 | 有效命中与上限 | 归零或失败 | 恢复与显示 |
| --- | --- | --- | --- |
| 周戍 | 3 格；有效弹击、盾击、槌击各扣 1；实际伤害限于剩余 HP | `行动 → 倒地 → 待重试`。当拍取消射击、握柄、制作和出口；不再接收伤害和掉落拾取，不在倒地函数内回满 | 普通过门不回血；首版无被动回血或药品。首次抵达**明确标记的整备检查点**才补至 3 并保存；普通安全区和重复踩点不补。倒地显示 0，松开旧输入后新按重试，才恢复快照 HP。 |
| 随行小满 | 无 HP；对她确实暴露的独立危险加 1 格恐惧，上限 3。周戍受伤不等于她受惊 | 3 格原地蹲停，不算死亡，不重置敌人 | 同层、可达且距离 ≤64，周戍新按 E 安抚；第 12、36 拍各响一次，第 36 拍退至 1 格，第 60 拍恢复跟随。占用期间不兼做机关。 |
| 独行小满 | 无血条；听见动静只改变威胁状态；确认发现后仍有逃离窗口 | 只有追上且身体在同一可达空间才算被抓；不播中弹、不扣周戍 HP | 村庄恢复安全起点、基础瓶和巡逻，已揭盖布保留；森林回安全树根，重给完整预警。城外失足走回，不重跑整章。 |
| 敌人、盾、场景物 | 首版普通战斗敌人本体 1 次有效命中即退出；持盾手盾面 2 点，盾值不是本体 HP；薄木挡和筐墙基础耐久 2 | 盾 0 只撤盾面；敌人退出只掉落一次；场景耐久 0 同拍撤掉相应碰撞和挡弹 | 敌人读姿态，盾和木挡读裂纹。小满恐惧与周戍血格分开放；HUD 不自行扣值。永久柱、门闩、剧情物没有可损耐久。 |

**统一数值口径（目标规则）**：60 个有效模拟拍为 1 秒。第 `t` 拍受伤则 `[t,t+42)` 不可再次扣血，`t+42` 起可受伤；暂停、独立演出不消耗保护时间。HP 永远在 `[0,3]`，一次受理只发一条 `actorHit`，归零另发一次失败事件。无敌不销毁整次攻击：同一发仍可打在位于角色前方的盾上，小满也按自己的暴露情况结算。首版建议 S1 出发和 C2 粮袋后的首次安全整备各保底满血；G2 独立守点从安全整备开始。其他检查点按实存血，存点前验证 1 HP 也能无伤离开。

## 3. 战斗判定：从意图到唯一结果

1. **先判是否能出手。** 只有可控、未倒地、双手空闲、装填结束的周戍能点射。按住不连发。开火后基础装填 54 拍；装备快装带且开火时已贴永久掩体才取 36 拍，离开掩体后不追溯重算。备用弹包只可结束一次正在进行的装填；未装填时按使用不消耗。
2. **再判空间。** 准星经当前镜头反算，投影只选择瞄准方向；命中按世界横向、脚底纵深和真实高度。比较有限射线上的首个有效交点，必须在该点的纵深也重叠；敌弹用同一空间查询。等距先实体、再盾面、再身体，同类按稳定实体 ID。一次点射只出一个结果：空、掩体、盾或本体；打碎的最后一击不穿透。回放至少保留攻击 ID、首个命中对象及位置。
3. **掩护与闪避有区别。** 全高实体本身挡住射线，不要求按键；半高掩体须移动后确实贴边、按住 Shift 压低身体且交点被挡。错侧、错纵深、空地按 Shift 都不挡。贴靠提示不是全方向免伤。残盾只挡穿过其部署位置和高度的首发，背后来弹不能提前耗盾。翻滚改变身体位置；首版保留盾击可被翻滚避开，不给枪弹和槌击额外全程免疫。
4. **最后才扣血。** 敌方攻击分预警、结算、收招；预警不造成伤害。结算拍用最终位置检查距离、纵深、高度、遮挡和目标是否有效。攻击实例用 `场次/敌人稳定ID/出手序号` 标识，每个目标每次最多吃一次；音效、补帧、持续接触不重算。

**同拍仲裁**：先处理暂停/演出/失败锁，再定移动、姿态和独占动作；结算合法的玩家出手，再按稳定 ID 处理仍有效的敌方出手，最后处理自动拾取、制作完成、机关完成、出口与存点。被打断预警的敌人不补发。敌方先于守点成功：G2 第 2700 拍若致命则失败，否则停火、保存「待送别」并等门边新按 E。碰撞体被首击打碎，后续独立攻击读取新状态。普通受击打断制作和握车，但不倒退已经推进的车轮；致命则一切未提交结果取消。

## 4. 敌人与潜行威胁：玩家凭什么能反制

| 类型 | 感知、预警与命中 | 玩家反制、退出和奖励 |
| --- | --- | --- |
| 铳手 | 可见入口登场；射界通畅才举器，沿用 36 拍预警、150 拍射后冷却。预警末按当拍射线结算；实体遮断则打在实体，玩家已离开锁定射线则落空。举器开始锁定瞄点，不在末拍瞬转追人 | 可借柱过街、换纵深或打断。带可见弹袋者退场掉备用弹包。第一轮须能从安全处看全预警。 |
| 持盾手 | 接近到可挥击距离再抬盾，建议预警 18 拍；结算时水平距离 <48、双方脚底纵深占地重叠、有效高度相交且中间无墙。不能在攻击距离外原地停住 | 命中真实朝向一侧且低于盾顶先损盾；背侧或越过盾顶命中本体。完整盾（2/2）退场才掉残盾；1/2、0/2 都不掉。 |

| 侧线带队者 | 复用上述一种行为，使用固定作者配置；战具外观在岔口就可辨认 | 退场额外掉配置的快装带或护送号牌，不加厚血门槛；绕开不锁主路。G2 守满后不生成无用物资。 |

## 5. 场景交互：只显示本拍真的能做的事

提示、输入消费和执行共用一次候选查询：角色/阶段允许 → 未被独占 → 身体横向到达配置边缘 → 同高可触且纵深差 ≤18（大物件取最近交互面）→ 中间无阻挡 → 满足前置状态。失败时不给成功音，不扣物。只有一个 E 候选：**失败态重试 > 已占用动作的继续/松开 > 安抚 > 主线门柄/机关/递物 > 工作台/换装 > 通用敲击**。同级按距离再按稳定 ID；HUD 报实际对象，如「车柄在另一侧」「等小满到门边」。有多个可选物资时显式选择再确认，不能挤占主线 E。

| 场景落点 | 成功才写入的变化 | 必须拒绝的情况 |
| --- | --- | --- |
| S2 窗板、薄木挡；S3 双人出口 | 从窗板背面放板后更新遮挡；薄木从完整到裂到碎；两人实际处在出口安全面且可同行才离开 | 正面隔板伸手；木挡碎后继续加固；周戍独自到门即切场。碎屑不阻小满，永久柱永远留路。 |
| C2 木帘、空筐、车柄、轮窝 | 远柱落帘或清掉威胁都可推车；握正确侧柄占两手，放开停在原位；轮入窝只发一次 `cartDocked`，抬闩后小满能沿车尾净空走出 | 站错深度推车；握柄同时开火、翻滚、制作；物品、残盾堵车轨或车尾；把打碎空筐误算为已开侧门。 |
| G1/G2 与送别 | 小满到等待点、周戍到机柄并主动启机；前庭稳定后计 2700 拍；停火后需走到门前送别才交权 | 未安置就开表；重试已守满快照重新刷敌；同一次长按跨过送别、演出和孩子首次主动迈步。 |
| 城外、村庄、北塔 | 低拱内不能站起；投瓶按实际落点传播；T2 敲门和 T3 案前交物各要真实站位和新按键 | 低层操作上层车柄；把听见瓶声当作捕获；把过门或上一个 E 当作片尾确认。 |

## 6. 拾取、使用与制作：一个决定要改变眼前走法

**格位裁决**：周戍一格常驻战具（快装带／号牌二选一），两个各装一件的消耗格（弹包、木楔、一次性残盾、下述木料）。残盾虽叫盾，按部署一次即耗尽归消耗格，不挤掉常驻战具。号牌不消耗，只在相邻安全锚示意等候或跟随，不传送小满。交权后背包封存在门内；小满只有剧情物和一个瓶位，瓶用空还可回固定补给点取。没有全队共享背包或剧情物占格。

- **拿起**：普通物资靠近自动拾。首版保留横距 <44；高度差按真实脚底 <60，另按掉落与脚底占地做纵深重叠，不以画面投影代替；隔墙不吸。先试入空格，成功后才写 `taken`、撤地面件、发一次 `pickup`。满包原物留地，不播成功音。安全处可主动交换，原件落回可达点；离开拾取范围前不自动拾回。
- **使用**：显式选消耗格再按使用；键位由实施者先核对当前输入映射，不能复用已有投瓶、翻滚或调试切房键而不做模式隔离。弹包无装填、木楔对裂/碎/已加固薄木、残盾预览压到轨道/门/同伴净空时均不消耗。木楔使完整薄木多承一次攻击且只能加固一次；残盾放下后固定在世界坐标，显示朝向和实际覆盖面。
- **来源**：敌人装备决定掉落，不抽第二次随机数。使用作者 `spawnId` 和掉落位构成物件 ID；同组两敌不撞 ID，带队者的普通与额外掉落可区分。地面件、背包件、已消费三态互斥；回退或跨房不能同时持有同一实例两份。

**首版只做一条真正的配方：废木料 ×1 → 木楔 ×1。** 这是本专项新增，木楔加固和残盾架设属于「使用」，不计作制作。木料放 S2 外檐靠永久柱的可选装卸角，旁设木工台，玩家在动手前就能看到下一段薄木挡。制作带来的选择是占一格带木楔保住下一次掩护，还是留格给弹包、直接走布行。木楔也可来自破障手，不强迫玩家打敌或找材料。首版不做采集树、随机词条、多层配方或小满武器。

| 制作环节 | 玩家所见与判定 |
| --- | --- |
| 准备 | 安全工作台、周戍在可达侧、手空闲且无指向台面的有效预警。E 查看「木料 1/1 → 木楔 1」，再新按确认开始。材料已在格中，产物原格替换，另一格已满也可做；缺料显示 0/1，不能开工。 |
| 加工 | 首轮建议 45 拍，显示进度。材料暂锁而不扣；松开确认键不重复开工。主动取消、走离、失去安全、受击或离场均解锁且不产出；暂停冻结。只在结算拍仍合法时提交。 |
| 完成 | 同一拍移除一个输入实例、原格写一个产物、发一次完成事件；产物有可复现 ID。切房、读档、连按不重发。工作台可复用，固定木料在同一检查点时间线只拾一次；安全台不能成为刷木楔的来源。 |
| 用出价值 | 允许「拾木料 → 制楔 → 加固完好木挡 → 多挡一击 → 两人过街」，也允许全程不碰工作台。若道具唯一效果只是背包数字变化，或台子占了必经门柄位置，本项不通过。 |

## 7. 检查点、反馈与实施顺序

**快照是同一拍的世界，不是几个单独存的计数。** 仅在安全落脚且无进行中交易时提交：种子与配置、场次及阶段、双方位置/姿态/HP/恐惧、敌人身份及状态、地面物/格位/消耗、可碎件与加固、部署物、机关/车轴、门闩、路线与同伴状态一起保存。重试先取消临时事件和制作锁，再原子恢复，重建通行面与提示，不重发旧掉落或完成音。普通切场继承当前局，不等于恢复快照。失败用时另记。V1 揭布是明确的保留例外；G2 守满另存待送别。首批要求局内重试，不额外引入磁盘存档系统。

前端每帧读取 HP/恐惧、盾或木挡阶段、当前合法交互、格位、制作进度；声音/短动效只消费模拟事件队列。沿用 `shotResolved`、`actorHit`、`coverBlocked`、`fearChanged`、`propBroken`、`pickup`、`interactUsed`、`cartDocked`；兼容旧字段，为新事件或扩展字段提供 `sceneId/tick/对象稳定ID/结果原因`。新增制作开始、取消、完成三种结果；完成才更新库存。调试回放能区分「没有命中」「被盾挡」「命中但在保护期」，玩家界面无需展示内部 ID。
