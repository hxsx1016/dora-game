## 4. 复用结论

### 4.1 《死亡细胞》只借三条节奏，不借外观

- **按键后第一张可辨认的姿势**：点射第 0 拍必须是“枪已抵肩、肩线压低”，不是先出枪口火光；跑射第 0 拍直接沿用 `run-shoot` 的持枪上身，不先切 idle。
- **快速动作仍能读懂的轮廓**：翻滚第 0 拍是收肩团块；翻柜默认用通用腾空，只有余量才画撑手；枪兵是“肩线 + 长杆”剪影；狗是耳朵/头/重心先变，再谈速度。外形轮廓优先于细节。
- **结束后接回移动**：点射 3 拍恢复后直接接当前跑步相位；翻滚结束接 run/idle 第 0 帧；小满落地接 walk；不插一段 idle 再起步。

只写能落到本项目动作的观察；不借服装、比例、整套控制器。

| 它解决的问题 | 保留哪几行逻辑的含义 | 映射到 Dora TypeScript | 哪部分不可照搬 |
|---|---|---|---|

## 5. P0 逐拍动作表

口径：1 拍 = 1/60 秒模拟步，不是美术帧。`现行` = 代码已有；`提案` = 建议时序，不动玩法数值。每张卡都按“触发｜第 0 拍｜关键姿势及保持拍数｜读取｜手脚锚点｜允许并行｜打断｜恢复｜正常例｜反例”写。

### A1 周戍点射

- **触发**｜`fire.pressed` 且非小满、非 `gripping`、非 `gripIntent`；`shoot()` 当拍结算。**现行**。
- **第 0 拍**｜枪口已抵准星，肩线压低 2–3 px，枪口一闪；脚底不动；腿保持当前 run 相位，不并脚。
- **关键姿势及保持拍数**｜0–2 射击姿（3 拍，第 0 拍压肩最大）；3–5 恢复（3 拍）；第 6 拍回 idle/run。枪口火光只 1 拍；`trace` 线渐隐。**现行** `traceT=0.12`（7.2 拍）；**提案** `shootT=6`，前端裁到 6 拍。两者都不动 `shoot()`。
- **读取**｜`shotResolved`（当拍）、`trace.x0/y0`（枪口起点）、`player.facing/vx`、`aimX/aimY`；不读 `fire.held`。
- **手脚锚点**｜前手 `(x+facing*10, y+0.70h)`；后手 `(x+facing*4, y+0.78h)`；枪口 `(x+facing*16, y+0.72h)`；脚底 `(x,y)`。世界坐标，原点左下；不跟 sprite bbox。
- **允许并行**｜跑/走腿相、上身肩袖、准星/弹道；空中点射可播 1 拍，但保持跳姿、不接地。不可并行：握柄、翻滚、翻柜、切房、安抚、长于 2 拍的跳跃。
- **被谁打断**｜`actorHit` 优先于射击姿；`coverBlocked` 可保留枪口 1 拍但不续后坐；翻滚/翻柜/握柄/切房/安抚/死亡立即收。
- **恢复到哪一姿**｜站立 idle，或跑步 `run` 的当前相位；不重置腿相。
- **正常例**｜按住 D 跑 2 秒，点一次左键：第 0 拍持枪肩线，3 拍后回跑，脚底不滑。
- **反例**｜按住左键连发；或同拍 E 在柄上仍出射击姿；或先播枪口火光再出持枪姿。
- **验收**｜连跑 3 次点射，脚底每拍位移与 `vx` 一致；枪口始终在枪上；不出现 idle 插帧。

### A2 周戍跑射

- **触发**｜`shotResolved` 且 `vx != 0` 或空中；`shoot()` 当拍结算。**现行**。
- **第 0 拍**｜`run-shoot` 的持枪上身叠在当前 `run` 腿相；双脚不并拢、不刹停；枪口在枪上。
- **关键姿势及保持拍数**｜0–2 上身射击（3 拍）；3–5 上身恢复；6 回纯跑。腿相 0–6 一直按 `runPhase` 推进，不因开火归零。**提案**；腿相数据**现行**。
- **读取**｜`shotResolved`、`player.vx`、`facing`、`runPhase`（由位移算）、`onGround`、`trace`。
- **手脚锚点**｜手同 A1；脚用 `run-1..8` 的脚底锚 (35,67)；`run-shoot` 下半身与 `run` 对齐，索引 1:1；不跟 bbox 底边上下弹。
- **允许并行**｜跑/走、贴靠减速 0.45×、空中 1 拍；不可并行：idle、蹲、握柄、翻滚、翻柜、安抚。
- **被谁打断**｜`actorHit` 可让上身缩 1–2 拍，但腿相继续；`coverBlocked` 不打断腿相；切房/死亡收。
- **恢复到哪一姿**｜`run` 当前相位；若已停则 idle。
- **正常例**｜跑动中每 0.3 秒点一次，连续 3 发；x 位移连续，脚下不出现双帧滑步。
- **反例**｜开火时把 `runPhase` 重置到 0；或播 `shoot-1` 站定姿；或双脚同时钉地却仍有 `vx`。
- **验收**｜3 发跑射的脚底轨迹与不开火跑动一致；`run-shoot` 与 `run` 下半身逐帧对得上；无瞬移。

### A3 周戍贴靠

## 8. 一帧 0 步 / 多步 / 切房 / R 的伪代码

不是通用动画框架，只解决本作的帧循环、一次性事件和实例切换。

```ts
// 一个模拟步 = 1/60 秒；clock.advance 返回 0..5 步。
function frame(frameDt: number): void {
  const n = clock.advance(frameDt); // 0..5

  // 0 步：不推进模拟、不推进姿势计时；只重画上一拍已提交的状态。
  if (n === 0) {
    render(play, pose); // pose.startTick 不随渲染帧走
    return;
  }

  for (let i = 0; i < n; i++) {
    input.beginStep(i === 0); // 第一步保留切房/重试后的边沿
    play.update(STEP, input);
    input.endStep();
  }

  // 多步：一次取走全部事件；按 seq 消费，age 用模拟 tick 算，不用渲染帧。
  const events = play.drainEvents(); // 0 步时这里本来就没有新事件
  for (const e of events) {
    const age = play.ticks - e.tick; // 0..n-1
    consumeOneShot(e, age); // 只改 pose/fx，不动 x/y/hp/knock
  }

  // 切房：先取旧队列，再换实例；新实例接旧事件，但旧房 knock 被过滤。
  if (play.wantRoom !== "") {
    const leaving = play.drainEvents();
    const key = play.wantRoom;
    const idx = ROOMS.findIndex((r) => r.key === key);
    current = idx; // registerPlay 会用 current 写 watch.room
    play = new Play(ROOMS[idx], { checkpoint: play.checkpoint });
    registerPlay(); // package.loaded['watch.play'] = play
    play.adoptEvents(leaving); // seq 重编号，tick 保留；旧房 knock 不迁移
    clock.reset(); // 新实例从 0 步开始；本帧不画
    clearPoseAndFx(); // 旧姿势/准线/声圈/未播事件全部丢
    return;
  }

  render(play, pose);
}

// R 重试：不迁移事件；新实例保留已提交检查点。
function retry(): void {
  input.consumeEdges(); // 清 pressed/released，保留 held
  play = new Play(ROOMS[current], { checkpoint: play.checkpoint });
  registerPlay();
  clock.reset();
  clearPoseAndFx();
}
```

要点：

- **0 步帧**只重画，不推进 `pose.startTick`、不推进 `traceT`、不推进任何动作计时；暂停也冻结动作与计时。
- **多步帧**的事件顺序按 `seq`，同拍事件按 emit 顺序（`stepPlayer` 的 `shotResolved` 先于 `stepEnemies` 的 `actorHit`）。一次性事件用 `play.ticks - e.tick` 算年龄，补 5 步时不会把第 0 步的枪口火光拖成 5 帧。
- **切房**先 `drain` 旧队列再换实例；`adoptEvents` 只过滤旧房 `knock`，`roomChange` 仍交给新前端。新实例的 `seq` 重编号，`tick` 保留。
- **R** 新实例、保留 `checkpoint`；旧事件不迁移，旧姿势/准星/声圈清空。
- **动画不反向制造玩法结果**：`render` 只读 `x/y/hp/gripping/onGround`；枪口火光、木屑、声圈、挡下姿势都不碰 `hp`、不碰 `x`、不发 `knock`、不生成 `bottleLanded`。
- **不为每个动作各造计时器**：只保留一个 `pose` 槽（`kind/startTick`）和一个固定 FX 槽（muzzle/dust/ring）；姿势年龄由 `play.ticks` 推导，跳跃/翻滚读 `vy/rollT`，不另开 timer。
- 当前 `app.ts` 只在切房 drain，动画前端接入时**每帧必须 drain 一次**；否则 256 条上限会丢最旧事件。这是前端接线，不是玩法改动。

## 11. 录像验收

四项交付：战斗 12 秒（街道 + 城门两镜）、检查站握柄中停镜、检查站安抚镜（独立起拍）、城门同街垒挡下/受击对照。中停与安抚各自单独成镜，不拼成一条 15 秒片。每项分别留逻辑回放、198 拍声画对齐（只战斗）、Dora 原生、默认入口真实键鼠、Windows 真机记录；战斗片与对照页关 HUD 和声音再给人看。不要把一个镜头的动作剪进另一个镜头。

### 11.1 战斗 12 秒（街道 + 城门两镜）

- 街道 0–3 秒：D 跑 2 秒；0.3 秒间隔点 3 次左键；只拍周戍跑射，街道靶兵 `warnT=0`，不拍敌兵预警/开火。
- 城门全片 180–720 拍：全片第 180 拍（3.00 秒）切到城门，`gate-hold` 取 `warnT=36` 的枪兵，先拍完整抬铳；全片第 198 拍（3.30 秒，切镜后 18 拍/0.30 秒）周戍命中，`alive=false`；镜头至少保留到全片第 216 拍（3.60 秒），216 时该枪兵仍垂铳、不闪枪口、不冒烟。命中即打断，不补第二发；其余时间留在守点构图。
- 跑射相位：同段各取一次脚落地、一次脚腾空；`shotResolved` 落在哪个模拟步，就在该步相亮枪口、收肩袖；双腿继续原步相，不重排。`run-shoot-3/7` 只作触地姿态参考，不绑定 96 拍。

肉眼标准（关 HUD/声音）：

1. 街道：连跑点射脚底不打滑、不瞬移；枪口在枪上，`shotResolved` 当拍一闪，肩袖短收，第 6 拍回原跑姿。
2. 脚落地与脚腾空两次点射都当拍可见；两次腿相不同，均无 idle 插帧、无双帧钉地。
3. 城门：枪兵不用红线也能看出完整抬铳；198 命中当拍收姿；216 仍垂铳，无补播枪火；静音/关 HUD 凭枪口短闪与肩袖后坐认出周戍开火，并能分清谁举铳、谁被打断。

### 11.2 检查站握柄中停镜（3 秒 / 180 拍）

输入：E 握左柄；D 推，车轴 1280→1344（约 60 拍），周戍 1240→1304；松 D、继续按住 E，停 2 秒（120 拍）；镜末仍按 E，双手留在柄上。左柄在 1304，脚和车轮都停。1408 是后续落窝点，不在本镜验中停。

肉眼标准：

1. 1280→1344 约 1 秒；车轴与玩家同移，脚不滑。
2. 停满 2 秒：轴到 1344，手仍握柄；脚不空踩、车轴不动；左柄 1304；不触发 `cartDocked`。
3. 镜末 `gripping=true`，不剪成松手动作；1408 不混进中停镜。

### 11.3 检查站安抚镜（独立起拍，10 秒 / 600 拍）

输入：本镜独立起拍，不继承中停镜的 E；小满已冻结、周戍在可安抚距离内，按 E 当拍记为 0；录到第 60 拍回 follow。周戍可俯身落肩，让手接近小满视线；双脚和碰撞体沿用原位。

肉眼标准：

1. 0–59 周戍 x/脚/碰撞不动；第 12、36 拍各一次指节触木，手到木板，不是只抬手。
2. 第 12、36 拍各一次 `knock`，与接触同拍；第一声后小满仍捂耳，第二声后小满才松肩、手放下/抬头；无第三敲。本镜拍 12/36，若按房间绝对拍读成 13/37，是同一步。
3. 第 60 拍回 follow，小满起身不跳帧；车轴不动；城门/塔门节奏没有混进来。

### 11.4 城门同一街垒：挡下/受击对照（单独页，不计入 12 秒战斗片）

- 同一 `GATE_ROOM` 街垒（x=520–600、y=0–44），同一机位；C1 `coverBlocked` 与 C2 `actorHit` 并排。
- C1：木沿起屑、周戍维持贴靠；`hp` 不变；没有 `actorHit`。
- C2：周戍缩肩 3–5 px、头/肩朝远离 `enemyX` 方向；`hp` 减 1；无木屑、无挡下姿势。

肉眼标准（关 HUD/声音）：

1. C1 只掉木屑不掉血，周戍保持贴靠；没有缩肩受击。
2. C2 只缩肩掉血，没有木屑、没有挡下姿势。
3. 观众能指出谁开了火、谁被打断、这一发落在木头还是人身上。
