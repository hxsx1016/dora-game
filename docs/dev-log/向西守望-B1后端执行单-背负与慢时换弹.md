# 《向西守望》B1 后端执行单 · 高石阶到第一场背负战

## 交付给玩家的这一段

周戍在风台牵起小满，一路走到高石阶，把她背到背上。再向前是第一间护送战斗房。玩家能边观察逼近的敌人边完成一次连线装填，亲手开出带效果的一枪，再走到安全出口。小满独行时仍从风台进入城外栈台。B2 从这间战斗房的出口续接后四段、第三段工台和团圆结局。

- 本次复跑 `check-repo.py` 得 25 组 TS/Lua、22 份 Markdown，通过。Dora 的 `requireProjectModule('tools.verify-story-gate')` 得 55/55；这个入口可直接读取完整结果。A 单的路线回放自行构造 `Play`、模拟切房并快进到守点末拍。正式菜单入口至出口的联调需要另留证据。
- `play.ts` 的 `stepGatePath()` 在高阶停留 30 拍后请求 `outside`；构造函数按 `outside` 设置小满单人操控。`app.ts` 的正式剧情持有 `storyRun`，标题独立试炼则从 `createTrial(App.rand)` 开新局。男主续段必须继承前者的路线、血量与种子，复用后者的战斗能力。
