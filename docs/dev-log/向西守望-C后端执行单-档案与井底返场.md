## C1 · 双通关记得住，井口只在正确时机开放

先交可玩的最小闭环：正式结局落幕后保存本地档案，回标题开新局后保留通关记录，重启应用后也读回。两种顺序分别通关留灯与团圆，均使重玩序章出现可探索的井口。新档、单通、双通但未主动拾取的 artifactOwned 都为 false。

玩家档案和 RunState 分离。当前 createRun 初始化 archive 会清跨局结果；从标题再玩和片尾回序章都需建全新局内状态并关联同一档案，清 finished、过门路线、材料、拾取和检查点。章节直达与 debug 不能写正式通关。死亡重开保留已有档案。存档写入走引擎本地可写目录，记录版本，采用可恢复的写入流程；缺失文件、损坏文件和不支持版本用隔离测试目录检验，保留原文件并明确报告恢复选择。自动测试不得覆盖用户正式存档。

序章井口只在周戍进屋寻小满、尚未靠柜特写的窗口可进入，原寻找路线仍通。沿侧灶、后院走到旧井，主动交互取出「时间穿梭器」，一次发放并保存。窗口前后、两种双通顺序、重复交互、退到标题重开和重启进程均验证。前端按真实可见性画声源和井光，通过既有命令入口触发交互。

## C2 · 博物馆去得了、回得来

获得穿梭器后首次使用进入虚构的现代抗日主题博物馆。字幕说明现代时间与纪念主题，使用本作原创文案。完成玻璃柜前收武器、听孩子脚步、末厅把灯转向西窗、两短叩回柜边这条交互链。博物馆各步有单一状态和输入边沿，暂停冻结。退出重启能从同一步续读；回程恢复原来寻柜任务、角色站位及必要剧情状态，既不跳过寻找也不重复发神器。artifactOwned、museumPhase、museumSeen 分别表示获得、进度、已完成。重玩男主可装备神器的彩蛋效果先按原规划做一段短暂移动残影，若会拖延返场闭环则列后续独立小单。
