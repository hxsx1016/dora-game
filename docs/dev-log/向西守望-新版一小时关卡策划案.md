# 《向西守望》新版一小时关卡策划案

2026-11-25 修订后的路线和时长以[双线后端开发规划](整合试玩/docs/向西守望-双线后端开发规划.md)为准。以下保留女主线四个城外房间与共同护送段的关卡细节。

供关卡、玩法和灰盒实施 Agent 使用。设计基线是新剧本的八章双线、27 场，以及项目已有的连续纵深移动、护送、掩体射击、推拉车和孩子潜行。本文定义新版应该玩到什么；同目录《向西守望-关卡重制-实施Agent提示词》说明怎样在仓库中交付。

## 一局的形状

**目标是约 60 分钟的纯玩法主线。**沿用此前的最快路线口径，以熟图、零死亡、跳过支线、合法利用掉落和捷径的一局来校准。章节交界处的分钟数是预算，实测前不能作为成品时长。独立剧情由演出系统接管。计时从 P1 首次获得控制开始，到 T3 案前主动交物结束。

| 累计玩法时间 | 章节 | 这一章玩家要做成的事 |
| --- | --- | --- |
| 00:00–03:00 | 序章 | 在倒柜后找到小满，带她一起走出井庭。 |
| 03:00–16:00 | 街道 | 读懂敌人控制的街面，自己选穿行路线，把两个人都带到牌楼后。 |
| 16:00–28:00 | 检查站 | 从锁住的门反向找到车轨，为推车争取空间，再接回同伴。 |
| 28:00–32:00 | 城门 | 安置小满，启动门机，守住 45 秒，亲自走到门边送她出去。 |

| 58:00–60:00 | 北塔 | 绕到塔门，敲门后主动走进室内，在案前交物。 |

前 32 分钟玩家替两个人找路，后 28 分钟让孩子用自己学会的观察方法走完。把最有压力的三段放在外檐过街、车轮入窝前、城门守点，再在城外给一整章无敌人的空间。后半的威胁来自能看见、能诱导、也能避开的巡逻。全程六处可选发现处在回环或短支路上，均不占下表预算。

## 一场战斗在地图上怎样成立

以 C2 为灰盒标尺。从棚口先看侧门和锁闩；镜头向右推进后，三条横向空间同时可读：

```text
远侧　棚柱后的拉环 ───── 实木帘落下的位置 ─── 接敌方向
中层　棚口 → 袋堆背后的小满等待位 ──────── 车尾汇合口 → 侧门
近侧　　　　空筐围挡 → 车柄 ── 暴露轨段 ── 轮窝 ── 连杆抬闩
```

手里有残盾的玩家可从近侧打开空筐短口，临时挡住一发，从车柄开始推进；空手玩家能绕到远柱落帘再回来。若已在棚口击退威胁，可直接推车。三条走法共享同一套车、帘和门闩。玩家在轮窝旁必须能同时看见车轮停住与连杆抬闩；小满停在中层时也必须有实际净空走到车尾。调难度优先动射击窗口、轨段暴露长度和安全位视角。

## 肉鸽与敌人掉落

每局固定地图骨架，开局选取一组作者配置。种子决定谁占哪个可见位置、带什么，以及部分薄木挡的初始情况。首轮在安全观察位完整展示一轮行为。S2、C2 各允许一处有明确回主路出口的侧线带队者；玩家站在岔口就能看清战具。G2 从任一有效配置进入都能在主垒守满 45 秒。

| 携带者 | 固定掉落 | 本局能改变的决定 |
| --- | --- | --- |
| 腰挂弹袋的铳手 | 备用弹包 ×1 | 可在当前装填期间消耗，立即装填完成。玩家能为下一次短跨留住一次反击机会。 |
| 持盾手 | 敌盾完整时掉残盾 ×1 | 在合法空地架设后挡一发。先击碎敌盾更容易通过，绕侧处理则可保住掉落。 |
| 持槌的破障手 | 木楔 ×1 | 给一处仍完好的可碎木挡增加一次承击机会。击退他还可能保住他正在拆的那块挡板。 |
| 侧线带队者 | 事先展示的快装带或护送号牌 ×1 | 快装带缩短永久掩体后的装填；号牌允许在相邻安全点示意小满等候或跟上。基础跟随和安抚始终可用。 |

周戍有一格战具、两格消耗品，每个消耗格放一件。背包满时物件留在地面，安全时可替换。不给必经门设置掉落需求。**同一场 S2 的两个合法结果**：玩家可先保住木摊挡、拿木楔、经外檐离开；也可放弃整组敌人，进布行落窗板，空手去检查站。到 C2 时，前者有资源保住近轨掩护，后者有完整的远柱解法。若两人最终都被迫清场才能走，这一组配置失效。

交权后，战具随周戍留在门内。小满线的重玩变化来自拾荒者的巡逻起点、备用瓶位置、狗的起始巡向和局部碎石分布。V1 保留基础补瓶位，F2 保留可观察两条路线的根后安全位。每个合法种子均可空背包通关。

## 破坏、检查点和演出交接

| 可变化物 | 变化后的空间后果 | 恢复约束 |
| --- | --- | --- |
| S2 外檐薄木挡 | 先裂后碎，失去中途短停位，仍可借两端石柱完成护送。 | 碎屑不堵路，同伴的等待目标始终落在永久柱后。 |
| C2 空筐围挡 | 打散后打开通往车柄的斜向短口，同时失去这段挡弹面。 | 通行、挡弹和同伴寻路同拍更新，车轨和门闩不受破坏。 |
| G2 前庭棚布 | 在 9–15 秒内由门链扯落，露出原本存在的次垒。 | 主垒及小满门柱永久有效，落布不伤人、不挪动角色。 |

检查点保存种子、已落下或捡走的物资、背包、机关、破坏状态、同伴与通行面。V1/V2 连续过门不中断调查；若整段失败，恢复安全起点、基础瓶和巡逻，保留已揭开的盖布。F3 失败回安全树根，完整重给预警。G2 守满后存为待送别，恢复时直接从停火状态继续。每次剧情交接只提供场次、角色站位、触发状态和归还控制权事件。G4 数数、T2 敲门回应和 T3 交物后的片尾独立计时，按住旧输入不能跳过下一次主动动作。

## 灰盒验收如何决定这版能否撑起一小时

1. **先搭章二到 C2 的连续样段。** 从街口起步，分别跑通外檐、布行、空手推车与带掉落推车。S1 至 C2 的单路预算合计 23:30。记录每次有意义的决定、主动穿行、交火、同伴跟随和纯等待各占多久。若连续几分钟只重复同一操作，应移走这个时长预算或补充真正改变走法的可玩空间。
2. **用整局回放检验一分钟表。** 对照最快街道路线、最快森林路线和有利掉落，跑一条同一种子、同一背包状态的合法全程。不能把不相容配置的各章最短时间拼成“最快纪录”。同时估算可并行和可跳过的动作，单列尚未证明的理论下限。
3. **用结果调整布局。** 初轮校准带建议取 57–63 分钟。若快速路线绕过大部分内容，优先把有空间价值的段落移回两路共有的必经段；若耗时主要来自等同伴、等巡逻或长空廊，就压缩该处，把时间转给新的可操作空间。保留 45 秒守点和短追逐的原有节奏。
4. **交付四项读数。** 分别给出最快合法回放用时、普通首通样本、独立演出总时长、六处可选发现增量。附逐章实测与预算差值。只有前一项与理论下限分析用来判断“一小时最快路线”目标。
