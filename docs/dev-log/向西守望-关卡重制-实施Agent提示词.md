## 肉鸽规则与掉落

1. 新开局生成种子，首轮有教学配置。场景位置、关键机关、永久掩体、同伴安全点和剧情交接固定。街道、粮棚和门庭从人工验证的遭遇组合中抽取敌人位置、携带物及可破坏掩体。安全观察位须能看懂本轮的主要变化。小满线只改变巡逻方向、非必需补给位置和局部地表暴露范围。
2. 周戍有一个战具位、两个消耗品格。普通敌人按可见装备固定掉落，奖励影响眼前或下一场，所有主线均可零拾取通过。普通物资靠近拾取，背包满时保留地面物件；战具在安全处主动替换，原件留到离场。G2 收尾停止生成已经没有使用机会的奖励。
3. 给每个可掉落敌人稳定标识。重试原子恢复检查点保存的种子、敌人、携带物、地面掉落、破坏状态及门机。再次击败同一敌人不能同时保有上一次失败前的收益。跨机房、灶屋门框等连续过景时不重抽、不重置调查窗口。
4. 交权后周戍的战具留在城门内。小满保有剧本道具，依靠投瓶、潜行和观察通过后半程。城外、溪湾、织房后院和北塔保持安全。
