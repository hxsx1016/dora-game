项目根 `dora-game/`，分支 `feature/watch-d1-graybox`，以 `41143fc` 为 D2 基线。程序由用户开发；从本文件接续规划与验收，不重做像素化和 Windows 组包。

## 已有证据

- 默认进试玩，`G` 切灰盒。320×180 逻辑画布，每像素 2 世界单位，`GROUND_PX=40`，显示取整、逻辑保留小数。
- `tools/make-windows-pack.sh` 组装 `dist/watch-windows-x64.zip`。本次交接复核 ZIP CRC 通过，SHA-256 为 `a4b4f71583fca8d03e20bd42128f690040f530f55f6457961e49da2d9d01c73f`。`Script/init.lua` 设置搜索路径，再载入 `Script/main.lua`。开发侧报告包内 Lua 已在 macOS Dora 上运行并比对截帧。
- **W01 保持待测**：Windows x64 解压，双击 `Dora.exe`，直接进入试玩，看中文、使用键鼠、关闭再打开。相机跟随前后实际点击同一柜角另记 Windows W02；数学反算和截图不代替这两项。
