**不要把两个探针行为带进正式游戏。**（1）连续六次发送 `W` 后，过期序号返回上次的 `auto_confirmed`、`seq=6`、`ticks=0`；以当前序号再发送一次 `W` 则变为 `seq=7`、`ticks=1`。这是合法的第七个命令，规则层无法知道它来自新按下还是系统重复事件。输入层应按物理键记录按住/抬起，控制器只在本次派发使序号变化时消费一次反馈。（2）探针的 `layout()` 把方块送回屏幕中心，正式棋盘缩放时只能重算格中心并重画已提交快照；`body/path/ticks/phase` 与会话序号保持不变。

**D3 离线包的四个检查动作**（另留 1 小时返工）：

1. 正解：`←、回车、→、→、→`。回声停在 `(0,0)` 的 a，本体在第 3 拍到 `(4,0)` 的出口，只结算一次。
2. 错解与恢复：`空格、回车、→、→`。最后一次向右应被挡，本体 `(2,0)`，拍数仍为 1。`R` 保留等待脚印并回到合作零拍；`T` 清空脚印，重新用正解可过。
3. 长按与失焦：前五次空格分别按下并抬起，第六次按住跨过自动确认，合作态必须保持零拍；抬起再按才到第 1 拍。再试切出窗口、在外松键、切回，新的按下只走一拍。
4. 非初态缩放：正解合作走完第一拍时，本体 `(2,0)`、回声 `(0,0)`、A 开。切换三种 D2 窗口比例后，角色仍占各自的格，阶段、路径、步数与门保持不变，方向提示、六个槽和出口可读；再按两次右能完成同一局。补验规划中的小尺寸，记录实际画布尺寸，勿把浏览器外框尺寸当成 `View.size`。
