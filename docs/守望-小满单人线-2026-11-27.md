# 小满单人线 · 出城到北塔连续段（2026-11-27）

基线 `feature/story-d-m2@e6d40da`（序章 P01/P02 已接入）。本轮只补正式游玩里缺的连接与可读反馈，不新增剧情分支。

## 从哪里开始玩

标题「开始游戏」→ P01 叫醒 240 拍 → P02 墙影 120 拍 → 逃柜（上限 450 拍，超时回门口重试）→ 入柜 51 拍 → 倒柜旁按 E 递针套 → 跟到街口 → 检查站推车 → 城门守点/送别。 **女主线（2/3 血）在数到二十后按新方向迈步出城**，从 `outside` 起就是本轮补的连续段：

1. 台面上按 E 拉开补丁红布车（96–140 原本挡住石阶口；拉开后车挪到 430–474，台面下水路一起放开）
2. 沿石阶下到 0 层，蹲着穿过 280–360 的 44 高拱洞
3. 车落窝后只挡站姿：蹲着从车底钻过去，沿墙根走到 1150 进村口
4. 空村：瓶架 E 拾瓶，桌下蹲着听脚步（脚近/脚远各一句），投瓶把拾荒者引到砖地，趁他走开过 440 通行线
5. 到 560–640 暗渠口蹲下钻过去（560 起提示「暗渠口 · 蹲下钻过去」），出院进森林
6. 森林两路：蹲着进 300–380 = 树根窄洞；站着进 700–790 = 旧渠（先到哪条算哪条，各一句字幕 + 写入跨房快照）
7. 1180–1260 溪湾：首次进入提示「水里那盏灯，和塔上一个方向」
8. 1450 林缘上岸进塔，塔门 E 敲两下，小满单人线落「留灯」结局（登记簿第一行小满、第二行留白）

## 本轮实际补的玩法

| 位置 | 之前 | 现在 |
| --- | --- | --- |
| 城外 96–140 | 只有台面，石阶口直通 | 补丁红布车实体挡住；E 拉开后车移到 430–474，`story.segments.outside_cart` 记一次 |
| 城外下层 | 车没落窝前整条封死 | 拉红布车同时把车挪到空窝（`cartAxle=endX`、`cartDocked=true`），下层放开、仍保留「站姿被车底挡、蹲 36 可钻」 |
| 空村桌下 | 无脚步反馈 | 蹲在 304–416 时每 90 拍按拾荒者距离播「脚步近了，别出声」/「脚步远了，趁现在钻」，事件 `storyBeat{beat=footstep_near|footstep_far}` |
| 空村暗渠 | 640 直接切森林 | 560–640 加暗渠口 zone/mark/dims，560 起提示蹲下钻；出院字幕改「钻出暗渠 · 北塔森林」 |
| 森林两路 | 只有草丛与矮台 | 300–380 树根窄洞（蹲行）、700–790 旧渠（可跑）两条 zone，首次进入记 `forestPath` 与 `segs.forest_burrow|forest_ditch`，各一句字幕 |
| 森林溪湾 | 无 | 1180–1260 溪湾 zone + 1220 mark，首次进入提示水里灯并记 `segs.water_lantern` |

反馈统一走既有 `flashSet` 字幕与 `storyBeat` 事件（前端可按事件加音效/镜头，不新增 UI 依赖）。跨房/重开/检查点恢复读 `run.story.segments` 还原红布车与两路/溪湾标记。
