## 二、门洞锁线（B1 第一步）

**规则**：守点 2700 拍守满只取血（`hpAtGate/maxHpAtGate`）；小满过门后到门洞按 E 才一次性锁线；`100*hp >= 80*maxHp`（上限为正）→ `soldier`，否则 `child`。

- 79/100 → `child`；80/100 → `soldier`；2/3 → `child`；3/3 → `soldier`
- 重复按 E、R 重试、续读都不再发第二条 `storyRouteLocked`
- 送别前 R：恢复 `gate-send`（待送别），路线仍未锁
- 送别后 R：恢复 `gate-count`（已锁路线 + 已换控小满）

## 三、两条路线复现（正式剧情入口）

启动：`~/Applications/Dora.app/Contents/MacOS/Dora cli run -p . --entry init.lua`，标题「新的旅程」。

### 路线 A：带伤送别 → 小满数完迈步出城

1. 序章靠近小满按 E 递针套，跟随走到街口 → 检查点。
2. 握车把按 E，按住 D 推车入窝 → 城门。
3. 守点守满 2700 拍，过程中被打倒会回绞盘重守；守满时血量 2/3。
4. 到门洞按 E 送别：`gateCountDone` 之前锁线，`route=child`。
5. 数到二十（1440 拍）后**松开所有方向键**，再重新按 → `storyExit route=child via=walk`，走进城外。

### 路线 B：守满 → 两下轻叩 → 长按牵手 → 背起 → 首战 → 换弹 → 出口

1. 同上到城门，守满时满血 3/3 → 送别按 E 锁 `route=soldier`。
2. 数满 1440 拍进入 `gate-wait`：第 1 拍、第 12 拍各一下轻叩（`knock count=1/2`）。
3. **松开 E 再按住**，累计 36 个有效拍 → `handHeld` + 台词「我们走吧。」→ `gate-hand` 演出 90 拍 → 切 `gatepath`。
4. 同行段走到高石阶 x=840 → 一次背起（`carryOn=true`、`gatePathEnd`+`carryStart`）；走到 x=1000 → `escort1`。
5. 首场护送：控周戍、小满在背上；开火 → 3×3 线盘 → 画完 → 装填走完再开下一枪。
6. 到 x=1500 出口 → `outside`，仍控周戍、仍背着小满。

## 五、慢时连线换弹（escort1）

- 开火（命中/打空/盾挡）后进入装填并开盘；`reloadT = 36 或 54` 拍（按天赋）。
- **240 作答拍 = 60 世界拍**：盘开时世界 1/4 速，只有每 4 个作答拍推进 1 个世界拍（回放实测 `answerTicks=240`、`worldTicks=60`）。
- 三类连线（只连相邻点、不重复、末点 8）：
  - 直连 `0→3→6→7→8` → `push`（推退 46px）
  - 经中心铃纹 `0→1→4→5→8` → `echo`（最近敌人 `awake=true`、`fireCd>=60`）
  - 经右上灯纹 `0→1→2→5→8` → `light`（下一枪无视掩体命中）
- 无效重画只清回起点，不重计时；超时（240 拍满）关盘、普通装填、清效果；暂停两钟同冻、恢复保留路径。
- 首发有效开火消费效果一次（`reloadApplied`），第二发普通。
