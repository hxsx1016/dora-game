# 《向西守望》明朝全局美术设定

**时代是明朝，地点是一座不具名的中国城池。** 故事不指定年号、战役或交战阵营。为使不同画师画出同一座城，衣着、街市和火器的造型统一取样于明代中晚期；这不等于给故事指定某一年。周戍是带孩子出城的守卒，小满是城里的八岁孩子。北塔是有人值夜、肯为她留一行名字的地方，不是宫殿，也不是现代军事基地。

本页是角色、敌人、场景、道具、动作特效、界面、标题和交付封面的美术依据。旧灰盒、商业素材和动作样片都不是时代设定。**本页只决定画什么，不改变玩家能做什么。** 房间 ID、路线、地形、碰撞、锚点、输入、事件与结算时机沿用玩法交付。以下是制作与验收标准，不表示现有贴图已替换。

## 一眼认出这座城

**新版按玩家视角定画风。** 序章以现有柜边、井庭和绞盘房的实机画面为母版。周戍正篇从牵起小满到进塔，全程沿用这套侧视像素比例、砖灰土褐色板、火光边缘和水墨界面。工台放在与序章军粮棚相同的灯下，换弹线盘沿用纸面与墨线。城门外数到一百的演出属于小满的视角。两条线都完整展示风台背景逐渐立体化，男主线随相握的双手抬镜见到周戍，自该镜起恢复序章画风。

小满单人线以《小小梦魇》第一作作为全部非角色画面的统一风格基准。从栈台到北塔，场景比例、侧视构图、前景遮挡、光影、雾、材质和镜头运动都按这个基准制作。所有人物沿用本作二维造型与动作，以脚底接触影融入低模场景。模型、纹理及房间布局按本作的明初海防卫城剧情制作。空村样张取桌下机位，桌沿压在画面上部，前景一条桌腿挡住半边院门，侧光擦过铁盆和砖面，让玩家从阴影里也看得清两个投瓶落点。北塔仍用同一套材质与镜头，让西窗一盏暖灯改变房间的气氛。

用三个重复出现的物件串起两条线：**木板上的两声敲击、车身左端的旧红布、腕上的指南针布套**。前半程隔着柜板看见小满的手，后半程由她用同样的手势敲塔门。远看是灰砖、暗瓦和木门，近看是手握过才磨亮的柜沿、车把和门闩。不要靠全街挂红灯笼、大屋顶或满屏水墨来代替时代设定。

序章与男主线保留侧视像素风。用砖灰与土褐交代建筑，靛青与麻布本色分开人物，暗朱给旧红布，暖黄给北塔窗火。背景少用最亮一档，留给手、车把和门缝。角色缩回实际游玩大小后，先读出轮廓和动作，再考虑盔钉、衣褶；墨迹、烟和纸纹都不能吞掉可走的边缘。

## 人物和动作

| 对象 | 定稿轮廓 | 动起来时要读到什么 |
| --- | --- | --- |
| 周戍 | 素铁盔、暗靛短袄、束带、布靴；旧布从护臂下露一点，不画成将领礼服 | 移动时衣摆让出腿形；贴柜时肩线低下。安抚时手从火器移到木板，指节接触处留亮边；握车时两只手都在柄上。 |
| 小满 | 双髻、短布袄、长裤、布鞋；针套以短绳绕腕，不用发光任务饰品 | 站姿能看见腕套，蹲姿先收膝、再收肘。拉车时人小柄高，双臂的斜线区别于周戍的平推；不为了够柄而改角色高度。 |
| 敌方火器手 | 同一时代的普通兵卒。以窄身、较直的下摆和长杆火器区别于周戍；不虚构民族符号来区分敌我 | 举器时肩与枪身从背景中分离；被打断就收掉预警姿。避免现代持枪待机、抛弹壳和战术背心。 |
| 拾荒者、林犬、守塔人 | 拾荒者是拢袖负布袋的平民，不穿匪帮制服；林犬没有战术挽具；守塔人先露提灯与执笔的手 | 拾荒者的转头、犬耳的转向要比衣褶和草叶更醒目。塔门打开时让灯照在交接的针套上，不用任务完成光柱。 |

**打击感来自接触的材质和节奏。** 开火沿既有 `shotResolved` 给枪口一闪、肩袖短促回收，然后烟散；不加抛壳、弹匣或装填等待。挡下读 `coverBlocked`：木柜起木屑，砖沿起灰，人不演受伤。受击读 `actorHit`：人缩肩失衡，柜子不替他响。已有预警线和准星是给玩家看的符号，不画成场景里的激光器。安抚两敲在动作第 12、36 拍，塔门两敲在进入当拍和第 12 拍；按既有 `knock` 对齐一次接触，不用动画另造敲击。力度与停顿由姿态、衣摆和烟尘表达，不增加命中停顿、后坐位移或硬直。

## 八个房间各画什么

| 房间（原 ID 不变） | 画面主景 | 必须给玩法留下的部分 |
| --- | --- | --- |
| 序章 `prologue` | 临街木铺半塌，柜后有旧账纸、砚与短毫笔；递出的是装着小指南针的布套 | 柜下留暗，伸出的手和套绳边缘见光。纸条仍进针套，不添书写交互。 |
| 街道 `street` | 灰瓦木铺、布招幌、矮柜；战火只在断木与烟上留下痕迹 | 柜顶保留能辨认的平沿，小满扶柜的手不被招幌或墙屑盖住。 |
| 检查站 `checkpoint` | 城门前的盘查处：木栅、案桌、木牌与木轮板车，不是公路岗亭 | 保留左柄、车身左端红布、落窝处和安抚用木板。木栅只装饰既有形体。 |
| 城门 `gate` | 砖券门洞、厚木门、木绞盘与街垒。门底见的是门外天光，不是电动闸灯 | 留出街垒边缘、门底缝和托门的手；绞盘仍是原交互，不增加升降步骤。 |
| 城外 `outside` | 同一段灰砖墙的外面，低拱、磨旧石阶、木轮车辙；墙根尽头重见塔窗 | 同一辆车换小满抓右柄，红布仍在车身左端，不随人物翻面。拱口不加垂布遮净空。 |
| 村口 `village` | 院墙、木桌、粗陶小瓶。硬砖有拼缝和亮边，软土用散点与浅足印 | 投的是原来的瓶子。两种地表在灰度下也能区分；落点、触地声圈与听觉范围不变。 |
| 森林 `forest` | 人走出的小路、草和落叶；从枝隙露出与前段同形的一格塔窗 | 草后要读得出犬耳和小满肩线；不以新路牌、灯带或可攀物提示路线。 |
| 北塔 `tower` | 北路砖石望塔，木门内一盏提灯；桌上纸簿与毛笔，最后留一行空白 | 敲的是木门。提灯先照见手、再照见「小满」与下一行；空行不盖印、不加完成标识。 |

## 道具、文字与界面

| 旧稿或样片里看到的东西 | 成品怎么画 | 保留什么 |
| --- | --- | --- |
| 现代步枪、弹匣、黄铜弹壳 | 木托、暗铁长管的明式鸟铳轮廓，配短闪与灰白烟；地上可留焦痕，不留弹壳 | 原点射输入、频率、射线与命中当拍；不模拟装填。 |
| 军用翻盖罗盘、铅笔、夹板 | 木盒内的指南针、布套、折纸、短毫笔与纸册；指南针不换成无关的风水摆件 | 递针、护针、交还纸条和簿中空行的叙事顺序。 |
| 探照灯、电灯、霓虹招牌、铁皮路障 | 远景用塔窗灯火，近景用提灯、墨字木牌、布幌、木栅 | 原来的亮暗指引、交互位置与障碍轮廓；不新增照明机制。 |
| 战术仪表、电子倒计时面板 | 体力用墨格、计时用清晰数字，字幕用浅色字配素底；只在标题、章题与封面用题签、印色 | 准星、预览圈、预警、键帽、数字与字幕是屏幕信息，不是假古董。小字优先可读；不添引导，不做仿古字谜。 |

**不采用的混搭：** 清式顶戴、剃发长辫、近代军帽、西式板甲、仙侠光效、工业路灯、现代弹药箱。外部图集可借步相、受力或脚底锚点；只换颜色而仍读成现代士兵，不算换装完成。

## 取样与验收

- 街市取样：[中国国家博物馆藏《南都繁会图》卷](https://www.chnmuseum.cn/zp/zpml/csp/202010/t20201028_247938.shtml)。取铺面开间、招幌挂法和行人相对尺度，不照搬南京地标、繁华密度或整幅构图。
- 戎装取样：[台北故宫博物院藏《明人畫出警圖》卷](https://digitalarchive.npm.gov.tw/Collection/Detail/1624?dep=P)。看头部、肩、腰带及衣摆怎样构成人形；图中是仪仗，不把仪仗服色和皇室纹样套给普通守卒。这里规定的角色配色与故事地点均为本作设计。
- 先审三张成品尺寸的画面：街道举器与柜边、城门内外的同一辆板车、塔门交针与空行。关 HUD 和声音，能靠形体区分守卒与孩子、靠材质区分挡下与受击、靠红布认出同一辆车，再补装饰。
- 八房背景、人物图集、道具图标、特效、菜单和封面按同一口径验收。既有碰撞体上画不下装饰就删装饰；接触对不上就修绘制锚点。不得要求玩法侧为美术变更尺寸、改时序或加接口。旧截图保留为灰盒证据，不作明朝美术验收图。
