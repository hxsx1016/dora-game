## 2. D2 正式入口与长链

### 2.1 GUI 键鼠注入的限制（如实记录）

本机 Dora SSR 1.10.2.6 的窗口内容是一个 `AXWebArea`（内嵌 Web IDE `localhost:8866`），游戏画布位于 Web IDE 页面内，不暴露 AX 节点。已尝试并全部失败：

- `computer_click`（Dora 内容区 x=126,y=615 与 x=252,y=478，含 foreground）；
- `computer_key` return（后台与前台）；
- `osascript activate` + `key code 36`。

失败判据：点击/回车后 Lua 桥始终读到 `screen=title`、`menu=0`、`room=nil`。

可用替代证据：
- `Dora cli agent preview` 离屏截图（2560×1440），OCR 出「开始游戏 / 选择章节 / 操作说明 / 护送试炼：肉鸽」，证明默认入口在渲染标题；
- 正式入口钩子 `watch.fe.startStory()` 走 app 的真实 `enterPlayRoom(0,"official",true)`，等价于标题「开始游戏」。

因此 D2 的「真实 GUI 点击」在本机不可复现，报告以「preview 截图 + OCR + startStory 正式入口」作为入口证据；这是环境限制，不是脚本绕过。
