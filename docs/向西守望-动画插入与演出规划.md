# 《向西守望》动画插入与演出规划

沿用[游戏分镜稿](向西守望-游戏分镜稿.md)的镜号。以下秒数用于第一版带声动态分镜。每条路线的约 90 分钟预算已包含这些镜头。演员近景用于交代手势、关系和物件去向，路上发生的动作尽量留在玩家当前机位里。

## 共同序章

| 插入位置 | 动画与声音节拍 | 输入与出镜点 |
| --- | --- | --- |
| P01 父亲叫醒小满，约 4 秒 | 先闻唤声，床帐才透光。第一人称从枕边坐起，父亲撑住床沿的手陷进褥子。顺着他转头的方向看见门缝。 | 机位在孩子眼高落稳后开放移动。第一步接醒来时已经看见的门。 |
| P02 门口墙影 → 逃柜，约 2 秒 | 影子落下时，一只碗从门后滚出来。碗沿撞上门槛，切回小满可玩的侧视镜头。跑动中只在屏边叠红晕，心跳随逃生剩余时间加快。 | 碗停、镜头归位和逃生起表对齐。入柜收掉红晕，留半拍柜外的脚步声。重试从门口的可玩姿态起。 |
| P03 柜边相认，约 3 秒 | 柜缝里先伸出两指。周戍用有补线的袖口揩走碎瓷，小满才敢把整只手递出来。用一声布擦木响记住袖口，城门重逢时复用。 | 周戍靠柜触发。镜尾回到两人同框，衔接递针套和跟随。井院探索窗口留在靠柜之前。 |
| P04 新增井庭墙根动作，约 1 秒 | 小满正要探头，枪火把两人的影子照上砖墙。周戍侧过肩挡光，小满沿他脚边看见布行窗板下沿。光灭后，磨亮的板边仍可辨认。 | 在双人通过墙根时播放上身动作。玩家继续走或退回，镜头保持当前朝向。 |
| P05 城门送别，约 4 秒 | 小满的手先扯紧补袖，周戍隔着布捏一下她的手，说「小满，慢慢数到二十。哥要是还没出来，你就往北塔走。」。落门声盖住城内兵声，最后留下外壕的水声。 | 由送出城门的成功状态触发。送别近景结束在小满手指张开的姿态，与风台首帧衔接。 |

## 风台与两种交权

G01–G03 共用约 24 秒。以门槛和小满脚底为固定参照，交付同一机位的五张关键帧。**0 秒**仍是平面城门；**6 秒**光擦过门框侧面；**12 秒**近处木板挡住后排石阶的一角；**18 秒**远墙和山体在雾里分开；**24 秒**脚边的影子落在立体风台上。人物始终保持二维。前十个数略快，数到十八时她贴近门板，「十九」放轻，留一口气才说「二十」。女声、风和水分别留音轨，便于调清最后一声「二十」。

| 走向 | 数完之后 | 何时交权 |
| --- | --- | --- |
| G04 小满单人线 | 门边空着。她把刚才抓袖子的手收回来，抚平针套。远处红布动一下，镜头留在她身边。 | 玩家重新按方向键才迈步。停留期间只循环风、布和呼吸。 |
| G05–G06 周戍同行线 | 风台安全。两下轻叩后小满抬手，按住交互时那道袖口的补线先入画。满 0.6 秒，周戍让她握住掌心，镜头顺手臂抬到他的脸，回到序章像素风。他说「我们走吧。」 | 中途松手，袖口退到画边，玩家可再试。握稳后恢复双人移动。先牵手走一段，到高石阶时小满才爬上他的背。 |

## 两线正篇与彩蛋

| 插入位置 | 动画、音效与控制 |
| --- | --- |
| F01 栈台第一次握车柄 | 小满的拇指陷进红布补丁。保留手的位置，用约半秒叠出家人缝布时拉紧最后一针的动作，再落回车柄。玩家持续拉车的输入贯穿回忆。 |
| F01 新增空村投瓶反馈 | 从桌布下保留整双鞋和暗渠入口。瓶击砖面时鞋尖停一下再转向，击铁盆时盆沿先颤，鞋跟随余响转过去。两种动画都跟随后端实际调查方向，玩家自行选择钻出的时机。 |
| F02 溪湾初见北塔 | 两条林路汇合后，塔灯先在脚边水面被涟漪揉碎。玩家走上溪岸时，枝叶让开，才看见实灯。用行走带动揭示，停步时水面继续动。 |
| M01 换弹起手与收手 | 小满探手，手指碰到线盘那一刻世界进入慢时。线盘输入立即可用，走线与光标按正常速度反馈。结算时手指沿已选纹样收回，回复常速。超时收为普通效果。第二次起直接复用短起手。 |
| M02 新增工台试握 | 第一次制成时，小满把成品递到哥哥惯用手一侧，周戍试握，她松手，约 1 秒。把材料扣除与成品出现放在同一确认结果上。重复制作仅播递交短动作。 |
| F03／M03 北塔登记，约 8 秒 | 两线共用门外两叩、门内回声和摊簿动作。单人线让笔尖悬在第二行，小满请守卒把灯挪到西窗。同行线从同一笔尖切周戍报姓名，第二行写满，小满松开针套，双手端碗。两版都以簿页和碗沿同框收尾。 |
| E01／E02 双通关返井 | 井底白灯、指南针玻璃与现代展柜用同一点反光做匹配剪辑。抵达博物馆后恢复自由步行。玩家转动西窗灯，第一声叩响留在展厅，第二声落在厨柜，回到哥哥伸出的那截袖口。 |

## 出样顺序与交付

1. **先做袖口与风台。** 用同一件袖口出 P03、P05、G05 三个手部镜头，再做从落闩到两种交权的两段带声样片。评审看观众能否在露脸前认出周戍，以及数完后能否自行发现下一步。
2. **再做两条可玩样段。** 小满线取桌下投瓶，周戍线取背负换弹。每段交一段正常速度录屏，保留玩家操作轨迹，检查遮挡能否读清、音效是否对齐落点、慢时进出是否影响作答。
3. **最后配对收尾。** 两个北塔结局并排剪一版，核对敲门节奏、执笔手势和第二行的归属。井底返场单独交一版含返回厨柜的完整转场。

后端交触发条件、所在拍、结果与交权时刻，前端交角色动作、场景分层、镜头曲线与分轨声音。现有试玩的 `prologue-give` 在确认交互后持续 60 拍，P03 靠柜特写需要独立起点。`gate-count` 已有 1440 拍数数与女主方向输入，男主重逢样片另需路线和长按进度。`tower-knock` 的敲门拍点与 `tower-given` 的交物、展簿节点可供尾声对表。验收时在风台中段暂停再续，在长按中途松开再握，在工台确认后读档，逐项核对画面、声音与持有物。
