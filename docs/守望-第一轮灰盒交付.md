# 第一轮灰盒交付：十字街 → 军粮棚

基线 `2f1d414`（feature/watch-2-5d，连续纵深 + V2 高清前端），任务分支 `feature/watch-level-rework`。
覆盖 S1 十字街、S2 布行与外檐、S3 牌楼后巷、C1 候检院、C2 军粮棚五段连续可玩。

## 试玩入口

- 引擎：Dora SSR 1.10.2.6，Web IDE `http://127.0.0.1:8866`。
- 项目：仓库根目录，入口 `init.lua`；`init.ts` 已改为 `start(root, 2)`，启动即进新版关卡 S1。
- 模式切换：`G` 在标题/旧灰盒/新版关卡试玩三层间循环；`F1` 回到 S1；`1`–`5` 直接跳段。
- 操作：`A/D` 横移，`W/S` 换纵深（上/中/下三档），`E` 交互（握车柄、放窗板、放帘、抬闩、拾取旁加固），`Space` 跳/翻越，`Shift` 贴掩体，鼠标左键射击，`F` 瞄准，`Esc` 暂停，`R` 重开本段。
- HUD 第一行：房间名 · 目标 · 本段计时 / 预算；第二行：总计时 · 路线 · 盾/楔/弹/牌/带 · 小满状态。

布行线 S2 比外檐线短 226 帧：外檐线要打碎薄木摊挡（2 枪）并从檐柱内侧换档。

差值 −95%：纯几何移动时间远小于设计预算。这不是"关卡做短了"能解释的，是**预算与可交互密度不匹配**，见调整清单第 1 项。

## 机制验收（程序化断言，全部通过）

```lua
-- 薄木挡：两枪先裂后碎，碎后同拍失去碰撞与遮挡
woodBroken true / broken true / hp 0
-- 持盾手：完整盾时死亡掉 1 个残盾；破盾死亡不掉
dropFull 1 shield / dropBroken 0
-- C2 远柱：E 放帘后木帘显形并记入 props，soft 只挡弹不挡人
curtain true
```

- 破坏：`Box.breakable` 扣到 0 后 `broken = true`，`slideX / limitDepth / groundAt / fallY / raycastSolid / coverAt / blockedShot` 同帧跳过，通路与遮挡同时改变；碎屑只画不挡。
- 掉落：铳手掉备用弹包（立即完成当前装填）、持盾手掉残盾（C2 轨段 E 架设，挡一发）、破障手掉木楔（给完好薄木挡 +1 承击）。
- 同伴：`joined` 跨房保留；布行线进 S2 时小满在布行等，放窗板后跟上；候检院两人在门前停，抬闩后同行；C2 推车入窝后沿车尾净空绕行。
- 机关：C2 推车一次（`CART_SPEED 64`，车柄 reach 70），车轮入窝后才允许抬连杆闩；闸门顺序与策划案 C2 三横向一致。

## 需要调整的地方

1. **预算与密度（最高优先）**：最快路径 65 s 对预算 23.5 分钟，差两个数量级。两条线都只经过 6 个战斗接触点、3 个机关、4 次换档。建议二选一：
   - 按实测重算预算：`最快路径 × 2.2`（首次通关含瞄准、观察、走错、受击重试）≈ 2.4 分钟/段，五段合计约 12 分钟；
   - 或在不违规（不降移速、不加空廊、不刷波、不重复推车）前提下补交互：S1 至少 3 个交错掩体与 2 条纵深岔路，S2 布行内加"后仓折回"折返，C1 队栏缺口与查验台各加一次换档，C2 轨段加两次停推（放帘/退敌/架盾各一次）。
2. **C1/C2 共用 `latchOpen`**：`raise_latch` 在 C1 就写入 `run.latchOpen`，C2 的目标判定会提前满足。驱动侧已用 `run.props["c2_latch"]` 绕过，玩法内应拆成 `c1Latch` / `c2Latch` 两个字段。
3. **小满跳高**：`CHILD_JUMP` 为绕过 52 高薄木挡临时提到 372（跳高 64.8）。按策划案 S2 应是"同伴等待目标落永久柱后"，不该靠跳高过挡。建议改回 320，并给同伴加"遇不可越障碍先退半档绕行"。
4. **C2 暴露轨段没有真实威胁**：火器手已后移到壳尾 1580，残盾/木帘的掩护价值体现不出来。需要在 1090–1240 轨段恢复一名可压制玩家但可被掩体挡下的火器手，否则 A 线"带盾推车"和 B 线"放帘再推"只是流程差异，不是走法差异。
5. **布行线 S2 掉血**：547 帧里掉了 1 格，来自檐柱内侧近身接敌。建议在布行柜台后加一处只挡弹不挡人的软掩体，或把盾手前摇拉长 8 帧。
6. **A 线盾链未自动验证**：驱动尚未接"杀盾手 → 走到掉落点拾盾 → C2 轨段 E 架盾"。需补 driver 分支，再跑一遍拿到带盾推车的实测帧数。
7. **真人准星**：自动回放用 `Play.aimAt()` 写准星，真人走 `input.mx/my`；需在真实键鼠下一局确认抬枪、装填与掩体三态的手感。
