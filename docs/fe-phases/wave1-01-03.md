## 一、`fe-01-gate-cuff-lowpoly`（风台 24s 转景 + 低模内核 + 袖口三镜 + 双出口）

- **触发口令**：`开工前端01` / `开工风台转景`
- **推荐分工**：**Gemini 主攻**（视觉构图、转景美感、袖口情绪与呼吸节拍）· **huihui(GPT) 支援**（双对齐点数学锁死、0.6s 长按与暂停恢复状态）
- **建分支命令**：
  ```sh
  git fetch origin --prune
  git worktree add ~/dev/.wt/2026gamejam/fe-01-gate-cuff-lowpoly -b feature/fe-01-gate-cuff-lowpoly --no-track origin/feature/fe-dual-route
  ```
- **独占文件范围**：
  - `Script/watch/fe/renderer/lowpoly.ts`（**核心共享底座，供 M1 后 `fe-04` 复用**）
  - `Script/watch/fe/scenes/gate_transition.ts`（风台 24 秒转景插件）
  - `Script/watch/fe/cutscenes/cuff_shots.ts`（袖口三镜与双出口交权插件）
  - `assets/audio/gate/*`（风声、海/水声、女声数数、布擦木、两下轻叩分轨资源或占位清册）

### 具体实现清单
1. **程序化 2.5D 低模投影内核（`lowpoly.ts`）**：
   - 提供可复用的低模几何体绘制原语：透视体块（城墙侧面、木栈台、石阶前后遮挡）、方向侧光面着色、景深体积雾层、**2D 角色脚底接触影**；
   - 支持连续形变因子 `morph ∈ [0, 1]`：`0` 时退化为严格正交像素平面，`1` 时展开为《小小梦魇》第一作尺度与高反差立体风；
   - 必须保证任意 `morph` 下，世界坐标 `(x, y)` 经 `cam.worldToScreen` 与低模走面严丝合缝，不破坏 `worldMapper` 反算。
2. **风台 24 秒转景（分镜 `G01–G03`）**：
   - 在 `room.key === "gate" && phase === "gate-count"` 时接管风台舞台与相机；
   - 进度取 `morph = Math.min(view.countElapsedTicks / view.countDurationTicks, 1)`，数字取 `view.countNumber`（即 `gateCountAtTick`），每秒 60 拍：
     - `0–479` 拍（0–8s，数 1–10 稍快）：0s 仍是平面像素城门，袖口退出处和门槛接得上送别近景；6s（360 拍）光擦过门框侧面显出第一道立体面；
     - `480–1079` 拍（8–18s，数 11–17）：12s（720 拍）近处木板渐渐挡住后排石阶一角；18s（1080 拍）远墙与山体在雾里分开；人物始终二维，脚底紧贴同一走面，锁死**小满脚底 + 门槛**两个画面对齐点；
     - `1080` 拍（18s）数「十八」贴耳上门板，`1260` 拍（21s）数「十九」放轻留呼吸，`1440` 拍（24s）才说「二十」且低模风台投影完整；
   - 声音、字幕、手势按数字变化各触发一次；暂停冻结同一拍与音频位置，恢复续播不重播。
3. **同一道补线袖口三镜（`P03` / `P05` / `G05`）**：
   - 抽象统一的「补过一道浅线的青布袖口」视觉组件，三处严格复用同一道补线纹样与配色：
     - `P03` 柜边相认（约 3s）：柜缝先伸两指 → 补线袖口揩走柜沿碎瓷（配布擦木声）→ 递手入柜；
     - `P05` 城门送别（约 4s）：小满扯紧补袖 → 周戍隔布轻捏她的手，台词「小满，慢慢数到二十。哥要是还没出来，你就往北塔走。」→ 落门声盖兵声、留外壕水声，镜头结束在张开的手指姿态以无缝衔接 `G01` 首帧；
     - `G05` 男主线风台重逢（约 4s）：数满二十且 `storyRoute === "soldier"` 时风台安静安全 → 侧墙传来两下轻叩 → 小满抬手 → 玩家长按交互键（首调 `0.6s`），补线袖口随 `holdProgress` 伸进画面；中途松手袖口退回画边可重试；满 0.6s 后握稳掌心，镜头顺相握的手臂抬至周戍脸部并**切回序章像素风**，他说「我们走吧。」（只触发一次）。
4. **女主线出口（`G04`）**：
   - `storyRoute === "child"`（或未接后端默认单人线）数满二十后：门边空着，小满收回攥袖的手抚平针套，远处红布随风轻动；只循环风、布、呼吸，**不弹按键提示**，静待玩家松开再重新按下方向键才迈步。

### 验收标准
- 可直接截出 `0 / 6 / 12 / 18 / 24` 秒（对应 `0 / 360 / 720 / 1080 / 1440` 拍）5 张同机位对比帧，小满脚底与门槛像素位置无跳动；
- 录出两条连续带声样片（单人迈步版 + 长按 0.6s 重逢切回像素风版），验证中段暂停续播与长按中途松手重试；
- 跑通 Dora TS→Lua 构建、`check-repo.py`、`verify-d6`、`verify-integration`。

## 二、`fe-02-reload-carry-craft`（背负姿态 + 3×3 慢时线盘 + 第三段工台）

- **触发口令**：`开工前端02` / `开工换弹工台`
- **推荐分工**：**huihui(GPT) 主攻**（3×3 邻接拓扑、双输入状态机、双时钟慢时、工台库存逻辑）· **Gemini 支援**（纸面墨线纹样美学、小满探手与试握动作）
- **建分支命令**：
  ```sh
  git fetch origin --prune
  git worktree add ~/dev/.wt/2026gamejam/fe-02-reload-carry-craft -b feature/fe-02-reload-carry-craft --no-track origin/feature/fe-dual-route
  ```
- **独占文件范围**：
  - `Script/watch/fe/renderer/carry_pose.ts`（牵手/背负/放下角色叠层表现）
  - `Script/watch/fe/ui/reload_wheel.ts`（3×3 慢时连线换弹全速 UI 插件）
  - `Script/watch/fe/ui/craft_bench.ts`（第三段安全武器工台 UI + 首次试握动画插件）
  - `assets/audio/combat/*`（线盘连入声、推退/回声/照明结算声、工台落器声）

### 具体实现清单
1. **牵手与背负姿态（`G06` + `carry_pose.ts`）**：
   - 保持序章像素风，区分三个姿态：风台后牵手过平路（两种步幅）→ 到高石阶周戍蹲下小满攀背 → 常规背负战斗移动；
   - 转身时小满平滑跟随周戍背侧锚点，与单碰撞体严密对齐；进第三段安全工台放下小满、出站重新背起。
2. **3×3 慢时连线换弹（`M01` + `reload_wheel.ts`）**：
   - 触发换弹时，小满从周戍肩后探手触碰线盘瞬间进入慢时（世界按 `worldDt = dt * timeScale` 推进，约 1/4 速，保证玩家在同画面里看得见迫近敌人和她的手）；
   - **线盘 UI 与作答时钟吃 `uiDt` 保持全速**（首调 4 秒作答时间）；
   - **双输入支持**：同时接受**鼠标拖线**与**键盘方向/相邻点选点**，只允许连接 3×3 相邻点（不可跳点/重复点）；
   - **三种有效路径与无引导反馈**：
     - 起点显示小满手指落位提示（不用文字教程），仅在玩家实际连入节点时纹样亮起并发声；
     - 起点→终点直连 = **推退**（`knockback`）；途经铃纹 = **回声诱导**（`echo`）；途经灯纹 = **照亮遮蔽**（`light`）；
     - 选线过程实时用**不同纹样 + 轮廓形状**（静音/灰度可辨）预览下次射击效果；
     - 无效路径松手可重画；超时收为普通效果（`normal`）；结算后手指沿已选纹样收回，世界与音效恢复常速；第二次起直接复用短起手动画；
     - 视觉风格：延续序章像素风的纸面与墨线，不画科幻霓虹 HUD。
   - **暂停与恢复**：暂停冻结世界慢时与 4 秒作答倒计时及当前已连路径，恢复后从同一路径继续作答。
3. **第三段安全工台与试握（`M02` + `craft_bench.ts`）**：
   - 与序章军粮棚同尺度、同灯光的明朝木案像素风界面；
   - 放下小满，将持有材料（如木纹筹、铃纹筹）排在桌边，清晰呈现两份武器方案（「引路灯铳」增强灯纹、「回声铳」增强铃纹）及各自强化后的连线效果预览；
   - 库存不足高亮缺项（即时反馈），取消保留全部材料；确认制成时与材料扣除对齐同一结果；
   - **首次制成动画（约 1 秒）**：小满把成品递到哥哥惯用手一侧，周戍试握、她松手，接回全身景并可立刻装备；重复制作仅播短递交动作；读档/重复确认幂等。

### 验收标准
- 录出正常速度实机/排演录屏，保留玩家操作轨迹，覆盖：三种有效路径（推退/回声/照明）、无效路径重画、超时普通效果、暂停续答、转身背负，以及工台缺料/取消/首次试握/读档；
- 产出一张「序章军粮棚 vs 第三段工台」同尺度画面对照图；
- 跑通 Dora TS→Lua 构建、`check-repo.py`、`verify-d6`、`verify-integration`、`verify-trial`。

### 具体实现清单
1. **共同序章三段演出（`P01`、`P02`、`P04`）**：
   - `P01`（约 4 秒）：黑场先闻父亲唤「小满」→ 第一人称睁眼床帐透光 → 父亲撑床沿的手陷进褥子 → 顺视线看见门缝 → 机位在孩子眼高落稳即交还移动；
   - `P02`（约 2 秒接可玩）：门槛内墙上两道人影被一道长影截断 → 瓷碗滚到脚旁撞上门槛 → 切回小满侧视开启限时逃柜（跑动仅屏边叠红晕 + 心跳随剩余时间加快）→ 入柜收尽红晕、留半拍柜外远去脚步；重试从门口可玩姿态起；
   - `P04`（约 1 秒叠加动作）：双人经兵房巷井庭墙根望十字街时，枪火将两人影子照上砖墙 → 周戍侧肩挡光 → 小满沿脚边看见磨亮的布行窗板下沿与石槽磨痕，光灭后板边仍可辨认（不锁玩家走动与镜头朝向）。
2. **明朝全局美术红线体检（对照 [明朝全局美术设定](../守望-明朝全局美术设定.md)）**：
   - 核查现有 8 房背景、周戍（素铁盔、暗靛短袄、束带、护臂旧布）、小满（双髻、短布袄、腕绕针套绳）、敌火器手（明代窄身直摆普通兵卒 + 木托暗铁鸟铳短闪灰烟，绝无弹壳/弹匣/战术背心）、拾荒者、林犬、守塔人；
   - 清除任何现代枪械/霓虹/探照灯/清代服饰残留；
   - 核对三张关键成品尺度图（街道举器与柜边、城门内外同一辆左端系红布的板车、塔门交针与空行）在关 HUD + 关声音 + 灰度下仍清晰可读。
