## 一、`fe-04-child-lowpoly`（小满单人线《小小梦魇》风低模四房）

- **触发口令**：`开工前端04` / `开工小满低模`
- **推荐分工**：**Gemini 主攻**（《小小梦魇》尺度、构图、前景压迫遮挡、侧光雾效与环境引导）· **huihui(GPT) 支援**（低模走面与 2D 碰撞/投瓶落点坐标对齐、材质回声事件绑定）
- **建分支命令**：
  ```sh
  git fetch origin --prune
  git worktree add ~/dev/.wt/2026gamejam/fe-04-child-lowpoly -b feature/fe-04-child-lowpoly --no-track origin/feature/fe-dual-route
  ```
- **独占文件范围**：
  - `Script/watch/fe/scenes/lowpoly_world.ts`（小满线四房低模主场景渲染插件，复用 `renderer/lowpoly.ts`）
  - `Script/watch/fe/scenes/village_undertable.ts`（空村桌下机位、鞋底可读、砖面/铁盆双反馈专章）
  - `Script/watch/fe/scenes/forest_creek.ts`（密林枯枝/犬追窄洞/溪湾水面碎灯倒影专章）
  - `assets/audio/child/*`（车轮木声、缝布回忆柔音、砖面脆响、铁盆余振、枯枝裂声、犬步与溪水声）

### 具体实现清单
1. **统一视觉基准（《小小梦魇》第一作 × 明初温州宁村所卫城）**：
   - 当 `view.visualMode === "lowpoly"`（女主线进入 `outside`、`village`、`forest`、`tower` 时）接管非角色渲染；
   - 所有建筑、巨型日常物、木桌、铁盆、石阶、拱洞、枝叶均用立体低模呈现；小满、拾荒者、林犬保持本作 **2D 造型 + 脚底接触影**；
   - 严格贴合现有 `rooms.ts` 走面、拱洞净空、碰撞体和投瓶落点，**不加任务箭头/浮签/光柱**。
2. **城外栈台 `outside`（分镜 `F01` 上半）**：
   - 同一段灰砖墙外侧、低拱、磨旧石阶、木轮车辙；拱口不加垂布遮净空；
   - 红布检修车由小满抓右柄，**旧红布必须固定在车身左端，绝不随人物转向翻面**；
   - **首次握车柄回忆（约 0.5 秒）**：小满拇指陷进红布补丁时保留手的位置，半秒叠出家人缝布拉紧最后一针的画面再落回车柄；玩家持续拉车输入不断档。
3. **空村桌下 `village`（分镜 `F01` 下半 · 重点验收样段）**：
   - 桌下构图：厚重木桌沿压在画面上部，前景一条桌腿遮住半边院门，侧光擦过铁盆沿与硬砖拼缝；
   - **暗处可读性硬标准**：阴影里必须一眼看清**拾荒者整双鞋底朝向**、**暗渠入口**以及**硬砖 / 铁盆两种投瓶落点**（灰度下仍可分辨硬砖拼缝亮边与软土散点足印）；
   - **两种落点不同视听反馈**：
     - 砸硬砖：干脆单响 + 拾荒者鞋尖停顿一下再转向调查方向；
     - 砸铁盆：盆沿先颤动 + 金属余响扩散 + 鞋底跟随余响转过去；
     - 两种动画严格跟随后端实际调查方向与落地事件，不限制玩家钻出时机。
4. **密林与溪湾 `forest`（分镜 `F02`）**：
   - 踩到/听见枯枝响时表现小满微顿侧耳的听声动作；
   - 草丛前景给犬耳和小满肩线留出清晰剪影；树根窄洞与旧渠两条分支靠自然形体与光线辨认，不摆路牌或灯带；
   - **溪湾初见北塔**：两路汇合后，塔灯先在脚边水面被涟漪揉碎；随玩家行走上溪岸，前景枝叶自然让开，才露出真正塔灯（停步时水面涟漪持续流动）。

### 验收标准
- 产出空村桌下实机截图：验证暗处鞋底、暗渠入口及砖面/铁盆双落点清晰可读；
- 录出空村桌下投瓶（含两种材质落点与玩家操作轨迹）完整录屏；
- 跑通 Dora TS→Lua 构建、`check-repo.py`、`verify-integration`。

## 二、`fe-05-dual-endings`（北塔双结局同机位配对演出 `F03` / `M03`）

- **触发口令**：`开工前端05` / `开工北塔双结局`
- **推荐分工**：**灵活认领**（推荐 huihui(GPT) 搭拍点/双线状态与交互框架，Gemini 精修宣纸留白/暖灯气氛/运镜）
- **建分支命令**：
  ```sh
  git fetch origin --prune
  git worktree add ~/dev/.wt/2026gamejam/fe-05-dual-endings -b feature/fe-05-dual-endings --no-track origin/feature/fe-dual-route
  ```
- **独占文件范围**：
  - `Script/watch/fe/cutscenes/tower_endings.ts`（双线北塔尾声与登记簿插件，挂在 `drawCutsceneOverlay`，不破坏原 `narrative.ts`）
  - `assets/audio/tower/*`（木门两叩、门内回叩两声、摊簿翻纸、落笔、端碗轻响）

### 具体实现清单
1. **共用前段节拍（总约 8 秒，精确对齐 `tower-knock` / `tower-given`）**：
   - 两线采用**完全一致的机位与叩门节奏**：门外主动轻叩两下（进入当拍与第 12 拍，对齐 `knock` 事件）→ 门内隔一息回叩两声 → 守卒推门提灯先照见手与针套 → 摊开宋明冷素宣纸收籍簿。
2. **女主单人线结局 `F03`（低模材质 + 西窗暖灯）**：
   - 沿用低模材质与镜头，以西窗一盏暖灯改变房间冷暖气氛；
   - 守卒接过针套与纸条，写下第一行「小满」，笔尖悬在第二行留白；
   - 台词：「朝西那盏灯，能留着吗？」→ 守卒将灯端去西窗，**留白的第二行不盖完成章、不加任务完成标识**；
   - 收尾构图：**簿页空着的第二行 + 碗沿同框**。
3. **男主同行线结局 `M03`（序章像素风 + 团圆暖室）**：
   - 沿用序章像素风；玩家牵小满跨过门槛，站在值夜室内；
   - 从同一个执笔悬停的笔尖切入，守卒写完第一行「小满」，**周戍亲口报出自己姓名**，守卒将第二行写满；
   - 小满终于把腕上的针套解下来轻放桌上，**两只手端碗**；
   - 收尾构图：**写满两行的簿页 + 碗沿同框**，落团圆结局。
4. **防误触与重试边界**：
   - 结局台词与定格读完前消化旧按键输入；室内重试不重关塔门、不重复追加登记行。

### 验收标准
- 并排产出两版北塔结局同机位对比截图（单人线西窗亮处清晰读出空着的第二行；同行线清晰读出写满的周戍姓名与双手端碗）；
- 并排剪辑/录屏核对两版敲门节奏、执笔手势与第二行归属完全对齐；
- 跑通 Dora TS→Lua 构建、`check-repo.py`、`verify-d6`、`verify-integration`。

## 三、`fe-06-well-museum`（双通关水井与现代抗日主题博物馆 `E01–E02`）

- **触发口令**：`开工前端06` / `开工井底博物馆`
- **推荐分工**：**huihui(GPT) 主攻**（双通关门控/中途续读状态机、反光匹配剪辑时序、穿梭器残影）· **Gemini 支援**（现代纪念展厅视觉氛围、字幕文案与构图）
- **建分支命令**：
  ```sh
  git fetch origin --prune
  git worktree add ~/dev/.wt/2026gamejam/fe-06-well-museum -b feature/fe-06-well-museum --no-track origin/feature/fe-dual-route
  ```
- **独占文件范围**：
  - `Script/watch/fe/scenes/well_museum.ts`（井院入口引导 + 反光匹配剪辑 + 现代抗日主题博物馆可玩展厅插件）
  - `Script/watch/fe/renderer/afterimage_artifact.ts`（「时间穿梭器」重玩男主线移动残影彩蛋特效插件）
  - `assets/audio/museum/*`（井底滴水声、反光切镜环境过渡、展厅静谧脚步、童声脚步回响、展厅第一声叩响 → 厨柜第二声叩响）

### 具体实现清单
1. **双通关条件门控（严格验证未开放 vs 已开放）**：
   - 仅当 `view.archive.childCleared && view.archive.soldierCleared` 为真，且位于序章**周戍进屋寻小满、尚未触发靠柜特写**的窗口时，开放侧灶通往后院深井的入口；
   - 单通关（仅女/仅男）或新档：完全不出现井院滴水引导与入口；原寻柜路线始终可正常走。
   - 引导方式：零浮签，仅靠**后院传来的滴水声与水光微闪**吸引玩家走近。
2. **井底反光匹配剪辑（`E01`）**：
   - 玩家俯身看井，井水中映出一盏此时不该亮的白灯，倒影位置精确与指南针玻璃叠合；
   - 拾取彩蛋武器「时间穿梭器」→ **以同一屏幕坐标的反光点作匹配剪辑**，无缝切入现代展柜玻璃上的同一点光。
3. **现代抗日主题博物馆自由步行与回柜（`E02`）**：
   - 虚构纪念展厅（克制、庄重、安静），入口字幕交代现代时间与抗日纪念主题；
   - 恢复周戍自由步行，走到玻璃柜前收起武器，远方响起一个孩子的轻脚步声；
   - 末厅留出充足安静探索时间，让玩家亲手转动西窗那盏灯 → 窗上映出宁村所井庭，留一句台词「小满，外头天亮了。」；
   - **声画回切**：第一声轻叩响在现代展厅，第二声轻叩落在明初厨柜板上，画面无缝接回哥哥伸出的那截补线袖口，交还寻柜任务；
   - **中途退出续读**：支持从 `museumPhase` 对应展厅位置直接恢复，离馆后不再重复触发发奖。
4. **「时间穿梭器」彩蛋特效（`afterimage_artifact.ts`）**：
   - `artifactOwned === true` 且重玩男主线装备穿梭器时，短暂重现角色上一段移动轨迹的冷白/微金残影（不干扰判定与视线）。

### 验收标准
- 演示并录屏三套状态：① 单通关/新档井口未开放；② 双通关完整流程（井院 → 反光匹配剪辑 → 展厅步行转灯 → 两声叩响回到补线袖口）；③ 馆内中途退出续读恢复；
- 跑通 Dora TS→Lua 构建、`check-repo.py`、`verify-integration`。
