# 《向西守望》前端交付单

场景取材于明初温州宁村所。井庭、十字街、水门与护城河依分镜入画，两条路线都走向北塔。请沿用 `feature/watch-level-rework` 的 `Script/watch/fe`、镜头、资源槽和现有键鼠菜单。女主线和男主线各约 90 分钟，各含约 30 分钟共同序章、约 60 分钟专属内容。双通关后的序章返场另计。后端交付快照、触发事件与回放种子，前端交付以下可实机对照的片段。

- [ ] **共同序章。** 第一人称叫醒，用墙影交代父母遇袭。躲柜计时配红晕与心跳，入柜后收声。周戍靠柜触发小手特写，兄妹隔墙看街战，绞盘外看见唯一出口，送别时小满攥住哥哥的袖口。
- [ ] **风台数到一百。** 样片用约 24 秒串起小满的数声。按归一化进度连续展开背景，交五个四分位节点的截图。数完后分别验证独自迈步与长按牵手，重逢时保持风台安静安全。镜号 G01–G06 见[游戏分镜稿](向西守望-游戏分镜稿.md)。
- [ ] **小满单人线。** 周戍血量低于 80% 时殿后战死，小满只听到门后归静。参考《小小梦魇》的儿童视点、巨大日常物和环境声提示，保留明初卫城物件与平面小满。用栈台红布车、桌下鞋底、投瓶落点、犬追窄洞、溪湾灯影做读图样段。最后两叩、交针套与纸条、名簿空行、西窗留灯依次可见。
- [ ] **背负与连线换弹。** 周戍血量达到 80% 后在风台与小满牵手，说「我们走吧。」两人朝北塔走，到高石阶后转为背负。换弹镜头看得到她的手和敌人。3×3 线盘接受鼠标拖线与键盘相邻选点，选线即时预览推退、回声或照明，用纹样加轮廓区别效果。角色和世界按后端慢时播放，光标保持全速。交三种有效路径、超时普通效果、暂停恢复与转身背负片段。
- [ ] **中期工台与团圆。** 第三段展示持有材料、两份方案与对应连线效果，制成后可立即装备并在下一房试用。扣料、装备和效果取后端结果。通关时兄妹两人站在值夜室内，名簿第二行由守卒写下周戍的名字。
- [ ] **水井与现代展厅。** 同档两条线都通关后，在周戍进屋找小满时开放后院深处的井。做井水映灯、拾取「时间穿梭器」、穿梭到现代抗日主题博物馆的连贯演出。展厅留出安静步行时间，让玩家亲手转动西窗灯，听见两声叩响，回到明初柜边。交一份单通关未开放、双通关已开放及中途续读的演示。

联调时前端读取 `storyRoute`、`countElapsedTicks`、`backCarry`、`timeScale`、`reloadPath`、`nextEffect`、`inventory`、`museumPhase`。后端按确认、扣料、射击、结局与拾取的实际顺序发带序号事件，前端在暂停与读档后按快照还原。11 月 26–27 日先交转景与换弹样段，11 月 30 日交两线实机录屏、对应拍号和分线计时结果。

## 分线画风与默认引导验收

- [ ] 小满线所有非角色美术以《小小梦魇》第一作为统一对照，覆盖空间尺度、场景与道具材质、构图、遮挡、镜头和灯光。角色保持本作二维造型。交空村桌下与北塔西窗各一张实机图，分别检查暗处能否看清鞋底和两种投瓶落点、亮处能否读出灯下空着的第二行。
- [ ] 男主线从风台牵手起延续序章像素风，包括兄妹、敌人、场景、换弹线盘、制作工台和团圆尾声。提交序章军粮棚与第三段工台同尺度对照图，以及从风台数完到切回周戍视角的连续录屏。
- [ ] 两线默认关闭目标箭头、任务清单、就近按键浮签、自动解谜与超时催促；操作表与按键辅助放在暂停菜单，供玩家主动查阅。保留按下、选中、受击、材料不足等即时反馈。风台数完时小满松开攥紧的手，女主线等玩家迈步，男主线听到轻叩后伸手等玩家按住交互。换弹时小满把手指放在线盘起点，纹样在玩家实际连入时回应。双通关后由井里的滴水声和水光引人走近。
- [ ] 用默认设置让三位首次试玩者独自尝试两线各自的风台交互、桌下投瓶和首次换弹。记录他们最先看向哪里、尝试了什么、何处打开操作表。若两人在同一处误读，先调整该处的构图、动作或声音，再用新玩家复测。
