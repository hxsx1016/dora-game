# 《向西守望》前端交付单

请沿用 `feature/watch-level-rework` 的 `Script/watch/fe`、镜头、资源槽和现有键鼠菜单。女主线和男主线各约 90 分钟，各含约 30 分钟共同序章、约 60 分钟专属内容。双通关后的序章返场另计。后端交付快照、触发事件与回放种子，前端交付以下可实机对照的片段。

- [ ] **共同序章。** 第一人称叫醒，用墙影交代父母遇袭。躲柜计时配红晕与心跳，入柜后收声。周戍靠柜触发小手特写，兄妹隔墙看街战，绞盘外看见唯一出口，送别时小满攥住哥哥的袖口。
- [ ] **连续 100 秒转景。** 与小满一起数，每过一秒背景都朝低模实景过渡，角色保持二维。以 `countElapsedTicks / 6000` 采样同一风台，门框、城墙、远山和投影陆续显出体积。交 0、25、50、75、100 秒五张同机位截图和一段连续录屏。归零时背景已完整成形，停在原地等待新方向输入。半程暂停和读档时画面应对上同一拍。
- [ ] **小满单人线。** 周戍血量低于 80% 时殿后战死，小满只听到门后归静。参考《小小梦魇》的儿童视点、巨大日常物和环境声提示，保留明初卫城物件与平面小满。用栈台红布车、桌下鞋底、投瓶落点、犬追窄洞、溪湾灯影做读图样段。最后两叩、交针套与纸条、名簿空行、西窗留灯依次可见。
- [ ] **背负与连线换弹。** 周戍血量达到 80% 后从侧道赶上小满，把她背在身后。换弹镜头看得到她的手和敌人。3×3 线盘接受鼠标拖线与键盘相邻选点，选线即时预览推退、回声或照明，用纹样加轮廓区别效果。角色和世界按后端慢时播放，光标保持全速。交三种有效路径、超时普通效果、暂停恢复与转身背负片段。
- [ ] **中期工台与团圆。** 第三段展示持有材料、两份方案与对应连线效果，制成后可立即装备并在下一房试用。扣料、装备和效果取后端结果。通关时兄妹两人站在值夜室内，名簿第二行由守卒写下周戍的名字。
- [ ] **水井与现代展厅。** 同档两条线都通关后，在周戍进屋找小满时开放后院深处的井。做井水映灯、拾取「时间穿梭器」、穿梭到现代抗日主题博物馆的连贯演出。展厅留出安静步行时间，让玩家亲手转动西窗灯，听见两声叩响，回到明初柜边。交一份单通关未开放、双通关已开放及中途续读的演示。

联调时前端读取 `storyRoute`、`countElapsedTicks`、`backCarry`、`timeScale`、`reloadPath`、`nextEffect`、`inventory`、`museumPhase`。后端按确认、扣料、射击、结局与拾取的实际顺序发带序号事件，前端在暂停与读档后按快照还原。11 月 26–27 日先交转景与换弹样段，11 月 30 日交两线实机录屏、对应拍号和分线计时结果。
