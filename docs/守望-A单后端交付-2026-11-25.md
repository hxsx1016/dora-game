## 2. 判定规则（实现口径）

1. 小满过门（`gate-send` 按住 E 送别）之前，周戍被击倒 → `gateFailed()`，回绞盘检查点重守，不锁线。
2. 守点最后一拍（`gateTick` 由 `holdTicks-1` 推进到 `holdTicks`）先结算本拍伤害，再 `settleRoute()` 锁存：
   - `hpAtGate = hp`、`maxHpAtGate = maxHp`（`maxHp <= 0` 时按 1 处理）
   - `storyRoute = 100*hpAtGate >= 80*maxHpAtGate ? "soldier" : "child"`
   - 发 `storyRouteLocked`，此后同一局不再重算
3. 数数固定 1440 拍（`GATE_COUNT_END`，24 秒 × 60 拍），暂停冻结在同一拍，续读按快照恢复。
4. `child` 路线：数满后必须出现「新的方向输入」（旧按键保持按住不算），迈出第一步发 `storyExit{via:"walk"}`，走进城外。
5. `soldier` 路线：数满后风台保持安全，第 1 拍与第 12 拍各一声轻叩（`knock count=1/2`）；必须重新按住交互满 36 拍（`GATE_HAND_TICKS`）才牵手。提前松手清进度并发 `handRelease`；松手后可重试；牵手与台词只触发一次。
6. 牵手完成发 `storyExit{via:"hand"}` 并进入同行段 `gatepath`；走到高石阶（`ox+840`）发 `gatePathEnd`，30 拍后进入 `outside`。

## 3. 两条路线怎么亲手走出来

### 3.1 从正式剧情入口（手玩）

1. 标题「新的旅程」→ 序章按 E 递针套、跟到门口 → 街口 → 城门检查点（握住车把、按住 E + 方向推车到窝）。
2. 城门：贴街垒（`x≈512`、按住 Shift）挡枪，或蹲掩体；守满 45 秒（2700 拍）。
3. 走到门洞（`|x-860|<=60`）按 E 送别，操控切到小满，数到二十。
4. 出口一（带伤，血量 < 80%）：等风吹完，**松开所有方向键再重新按 D/A**，小满走出城外。
5. 出口二（血量 ≥ 80%）：数完后听到两下轻叩，**重新按住 E 满 0.6 秒**（中途松手可重试），牵手进同行段；走到高石阶自动收尾。

## 4. 前端可直接使用的字段与事件

### 4.1 `Play` 公开字段（每拍更新，只读消费）

| 字段 | 类型 | 更新时点 |
| --- | --- | --- |
| `phase` | `string` | 相位切换当拍（`gate-idle`/`gate-hold`/`gate-send`/`gate-count`/`gate-walk`/`gate-wait`/`gate-hand`/`gatepath-start`/`gatepath-stair`） |
| `storyRoute` | `"child"\|"soldier"\|""` | 守点最后一拍结算后，之后不变 |
| `storySettled` | `boolean` | 同上 |
| `hpAtGate` / `maxHpAtGate` | `number` | 同上，锁存值 |
| `hp` / `maxHp` | `number` | 受击/恢复当拍；跨房与重试沿用 |
| `countTick` | `number` | `gate-count` 每拍 +1，上限 1440 |
| `handTicks` / `handNeedTicks` | `number` | 长按每有效拍 +1；`handNeedTicks` 恒 36 |
| `handArmed` | `boolean` | 松手后置真：需重新按下才算 |
| `handDone` | `boolean` | 牵手完成当拍置真 |
| `lineSaid` | `boolean` | 台词首次触发后置真（只一次） |
| `tied` | `boolean` | 牵手完成当拍置真，跨房保留 |
| `pathDone` | `boolean` | 同行段走到高石阶当拍置真 |
| `knocks` | `number` | 轻叩累计（1/2） |

### 4.2 一次性事件（`drainEvents()` 消费，`PlayEvent{seq,tick,name,data}`）

| 事件 | `data` | 触发时点 |
| --- | --- | --- |
| `storyRouteLocked` | `{route,hp,maxHp,hpAtGate,maxHpAtGate}` | 守点最后一拍、伤害结算后，每局一次 |
| `gateCountDone` | `{route,countTick,hpAtGate,maxHpAtGate}` | 数到二十的第 1440 拍 |
| `knock` | `{count:1\|2,x,room}` | `soldier` 数满第 1 拍、第 12 拍（既有事件复用） |
| `handHeld` | `{handTicks,handNeedTicks}` | 长按达到 36 个有效拍 |
| `handRelease` | `{handTicks}` | 中途松手且已有进度时 |
| `storyLine` | `{who:"周戍",text:"我们走吧。"}` | 牵手完成当拍，每局一次 |
| `storyExit` | `{route:"child"\|"soldier",via:"walk"\|"hand"}` | 迈出第一步 / 牵手演出结束 |
| `gatePathEnd` | `{x,tied,ticks}` | 同行段走到高石阶 |

### 4.3 `adapter.ts` 新增帧字段

`storyRouteLocked`（锁线脉冲）、`storyRoute`、`gateRested`（到达安全待机）、`handJustTied`、`handReleased`、`storyLine`、`storyLineText`、`storyExit`、`storyExitRoute`；`WorldPrompt` 新增可选 `progress`（0–1），`gate-wait` 时给 `handTicks/handNeedTicks`。

`hud.ts` 在 `gate-wait`/`gate-hand` 画 400 宽琥珀进度带并显示 `n/36`；`narrative.ts` 把这两个相位纳入电影黑边；`camera.ts` 推近到 1.12/1.22。
