# 《向西守望》多平台与 KTR 掌机适配说明

> 对应分支：`exp/full-remediation`（基于 `origin/exp/multi-device-adapt`，已合入全阶段玩法/UI/叙事/字体整备；音频总线由并行分支 `feature/audio-overhaul` 负责）
>
> 对应赛事：**2026 开源游戏开发大赛（OSGJ） · 多端发行与 KTR 掌机赛道**（全平台统一支持**键鼠 / 触屏 / 手柄**三种操作模式；代码许可 **Apache-2.0**）

## 一、架构解耦与目标设备

游戏将 **轴 1（平台能力与视口：`Script/watch/platform.ts`）** 与 **轴 2（三模操作输入：`controls_config.ts` / `aim_assist.ts` / `input.ts` / `touch.ts` / `gamepad.ts`）** 深度解耦：

| 项目 | 规格 / 机制 |
| :--- | :--- |
| 目标机型与载体 | 1. **KT Pocket KT-R1 / KT-R2**（4.5" 3:2 `1620×1080`、4.2" 4:3 `1280×960`，Android / KOS）；<br>2. **Android 手机 / 平板**（独立签名 APK，默认 `fullUser` 允许横竖屏自由切换；亦支持 Dora SSR Go 源码运行）；<br>3. **Web 浏览器**（GitHub Pages 静态部署包与离线 HTML 单目录包，桌面/手机横竖屏自适应）；<br>4. **Windows x64 桌面便携包**（D3D12 / OpenGL 双后端）。 |
| 平台能力矩阵 | `PlatformCaps` 统一声明全屏切换（桌面 + Web）、退出游戏（桌面 + 独立 Android APK；Web 与 Dora Go 源码模式自动隐藏且绝不调用 `App.shutdown()`）、Android 系统返回键（标题页 2 秒双击退出提示）、触觉微震动、Web 音频首手势解锁与 `App.safeArea` 刘海/手势条避让。 |
| 生命周期保护 | 切后台（`WillEnterBackground` / `DidEnterBackground` / `WindowFocusLost`）自动暂停局内对局、静默落盘存档、暂停音频并清空触控与手柄瞬时按键，杜绝卡键或丢档；彻底避让 Dora Go 退出热键（`Back + Start`）。 |

## 二、全平台统一三模键位（键鼠 / 触屏 / 手柄）

**任何平台**均可随时使用键鼠、触屏或手柄。默认处于「自动切换」模式（根据最近一次有效输入热切），亦可在暂停菜单末尾进入 **「操控设置」** 二级页手动锁定模式或调节参数；全部偏好统一持久化至 `watch-save/controls.txt`（兼容自动读取旧版 `touch.txt` / `gamepad.txt`）。

### 1. 通用与菜单导航
- **开机序幕（Splash）**：4.65 秒团队「局外人」标 → 《向西守望》主标，0.25 秒后键鼠任意键/点击、手柄任意键、触屏轻触或系统返回键均可跳过。
- **手柄菜单方向与确认**：左摇杆（死区 `0.55`，连发 `0.38s / 0.13s`）或十字键；默认 Xbox 布局（`A` 确认 / `B` 返回），可在暂停「操控设置」切为日系布局（`B` 确认 / `A` 返回）。
- **操作说明分页**：在「执器要诀」页按 `LB / RB`、`← / →` 或直接点选右上页签，查看完整的「键鼠 / 手柄 / 触屏」三套操作指南。
- **暂停与重试检查点**：手柄单按 `Start` 暂停，**长按 `Back` 0.55 秒**重试检查点（顶部显示进度条）；同时按 `Back + Start` 静默锁定以避让 Dora Go 退出热键。
- **竖屏掌机台**：当窗口高宽比 `H > W × 1.05`（手机竖屏 Web 或旋转后的 Android APK），自动切为「上半屏 16:9 完整无裁切舞台 + 顶部状态条 + 下半屏宋明水墨掌机操控台」，零手指遮挡画面。

## 三、3:2 / 4:3 掌机屏与多比例视口细节

- **镜头横向视野补偿（`Script/watch/fe/camera.ts`）**：16:9 及更宽屏幕保持 `aspectComp = 1.0` 零变化；在 `1620×1080`（3:2）与 `1280×960`（4:3）下保守补偿缩放（下限 `0.82`），避免枪战房间横向视野被截窄，同时保持 `worldToScreen` / `screenToWorld` 严格互逆与风台双锚点锁定不变。
- **动态假鼠标隔离（`TouchRouter.isSuppressingSyntheticMouse()`）**：仅在真实手指按下及抬起后 250ms 内屏蔽 SDL 单指合成假鼠标，既彻底消除安卓触屏摇杆误射，又保证 Android 平板/掌机外接实体键鼠零阻碍运行。

## 四、团队真机 5 分钟冒烟验收清单

1. **导入/安装运行**：通过独立 Android APK、Web 站点或 `tools/make-dora-source-pack.sh` 源码包启动 `init.lua`，确认统一北塔图标、4.65 秒开机品牌序幕与任意方式跳过正常。
2. **全平台三模切换**：进入暂停菜单 →「操控设置」，验证在任意平台上可切换 `自动 / 键鼠 / 触屏 / 手柄` 及手柄确认键布局、磁吸、触控大小与透明度，重启后仍持久化保留。
3. **Android 横竖屏旋转**：旋转手机确认横屏全屏浮钮 ↔ 竖屏上半 16:9 + 下半水墨掌机台无缝切换，且标题/暂停页可正常使用「退出游戏」与双击返回退出。
4. **KTR / 手柄混用触屏**：验证左摇杆斜走、右摇杆瞄准磁吸、3×3 换弹盘摇杆 8 向直推与手指划屏混用、小满轻推慢走与 `B` 取消投瓶，以及 `Back + Start` 避让 Dora Go 退出条。
