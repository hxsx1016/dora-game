# 《向西守望》多平台与 KTR 掌机适配说明

适用于 2026-11-28 发行工作树，面向 2026 开源游戏开发大赛多端发行与 KTR 掌机赛道。项目代码许可为 Apache-2.0。

## 一、发行目标与输入

| 目标与载体 | 支持的输入 | 操作设置与视口 |
| --- | --- | --- |
| [Windows x64 便携包](../Script/watch/targets/windows/index.ts)（D3D12 / OpenGL） | 仅键鼠 | 键鼠单页，可切换全屏 |
| [Android 手机 / 平板 APK](../Script/watch/targets/android/index.ts) | 仅触屏 | 触屏单页，支持横屏浮钮和竖屏掌机台 |
| [KTR 掌机 APK](../Script/watch/targets/handheld/index.ts)（KT-R1 3:2 / KT-R2 4:3） | 手柄、触屏 | 默认手柄，可自动切换或锁定其中一种，固定横屏 |
| [Web 浏览器](../Script/watch/targets/web/index.ts)（在线或离线包） | 键鼠、触屏、手柄 | 支持自动切换或锁定其中一种，支持横竖屏 |

源码项目从根目录的 [init.lua](../init.lua) 运行。未指定目标时，桌面选 `windows`，Android / iOS 选 `android`，浏览器选 `web`。在掌机上用 Dora Go 调试手柄时，启动项目前设置 `package.loaded["watch.target"] = "handheld"`；掌机专用 APK 已绑定该目标。[目标解析](../Script/watch/target.ts) · [掌机启动引导](../tools/handheld-boot.lua)

桌面与 Web 支持切换全屏；桌面与独立 Android APK 支持游戏内退出。手机与掌机 APK 在标题页两秒内连按系统返回键可退出。局内切后台或窗口失焦时会保存当前会话、清理瞬时输入并暂停游玩与音频。[应用事件处理](../Script/watch/app.ts)

当前主线的 Windows 便携版在局内单击窗口关闭按钮会自动存档并暂停。重试检查点需按住 `R` 0.65 秒，蹲伏可在设置中改为点按切换。键鼠操作小满时可按住 `F` 或左键瞄准，松开投瓶，右键取消。公开试玩 `v0.1.0` 的操作以其包内说明为准。

## 二、各输入方式的键位

按上表选用对应列。「执器要诀」仅列出本目标支持的输入页。设置保存在 `watch-save/controls.txt`，Windows 便携包使用 `saves/settings.ini`。[配置读写](../Script/watch/controls_config.ts)

### 1. 通用与菜单导航

- **开机序幕（Splash）**：4.65 秒团队「局外人」标 → 《向西守望》主标，0.25 秒后可用本目标支持的确认键、点击、手柄按键或轻触跳过。
- **手柄菜单方向与确认**：左摇杆（死区 `0.55`，连发 `0.38s / 0.13s`）或十字键；默认 Xbox 布局（`A` 确认 / `B` 返回），可在暂停「操控设置」切为日系布局（`B` 确认 / `A` 返回）。
- **操作说明分页**：在「执器要诀」页按 `LB / RB`、`← / →` 或直接点选右上页签，切换本目标提供的操作页（KTR 两页，Web 三页）；单输入目标直接显示对应页。
- **暂停与重试检查点**：手柄单按 `Start` 暂停，**长按 `Back` 0.55 秒**重试检查点（顶部显示进度条）；同时按 `Back + Start` 静默锁定以避让 Dora Go 退出热键。
- **竖屏掌机台**：当窗口高宽比 `H > W × 1.05`（Web 或 Android 手机 / 平板目标），自动切为「上半屏 16:9 完整无裁切舞台 + 顶部状态条 + 下半屏宋明水墨掌机操控台」，零手指遮挡画面。

### 2. 周戍（军人线 · 2.5D 枪战与护送）

| 操作 | 键鼠 | 手柄（通用 / KTR） | 触屏（横屏浮钮 / 竖屏掌机台） |
| :--- | :--- | :--- | :--- |
| 移动与纵深 | `WASD` / 方向键 | 左摇杆（方映射斜走）/ 十字键 | 左侧宋明水墨动态摇杆（2.5D 四向） |
| 瞄准与开火 | 鼠标瞄准 + 左键 | 右摇杆 360°（含共享敌兵/盾顶磁吸）+ `RT / X` | 直接点屏射击，或按住「开火」钮 360° 拖瞄松手发射 |
| 贴靠掩体 | 按住 `Shift` | 按住 `LT / LB` | 「掩体」点按开关（再点或翻滚自动离掩） |
| 翻滚 / 翻越 | `Space` | `A` | 情境钮（近矮柜自动显示「翻越」，平地显示「翻滚」） |
| 交互 / 推车 | `E`（推车按住 `E+D`） | `Y / RB` | 右上大交互钮（牵手长按进圈，推车单点自动锁握柄） |
| 时间穿梭器 | `T` | `L3`（按下左摇杆） | 持有神器时自动浮现「穿梭」钮 |
| 护送本领折笺三选一 / 折戟小结 | `1/2/3`、`←/→ + 回车` 或鼠标点击 | `←/→` / `LB/RB` 切卡 + `确认/L3/R3` 习得（**手柄下亦可直接触屏点卡**） | 居中折笺与「重整再赴/返回标题」按钮直接轻触 |
| 3×3 慢时连线换弹 | `Q` 手动开启 / 鼠标点击或拖线 / 方向+回车，右键重画 | 左摇杆 **8 向直推（支持斜角 `0→4→8`）** / 十字键+确认，返回键/X 重画（遵循 Nintendo/Xbox 布局） | 放大热区单指点击或一笔滑连 + 顶部「重画」钮（**手柄模式下同样可直接划屏**） |
| 第三段安全工台 | 鼠标 / `A/D` + 回车 | 左摇杆/十字键/`LB`/`RB` 切卡，确认制作/佩用，返回收起 | 放大方案卡与「收起」钮直接点选 |

### 3. 小满（单人线四房 · 四向潜行）

城外、空村、森林、北塔均开放纵深。上 / 下分别向远处 / 近处移动；进入低拱后会保持蹲姿，走出后才能站起。[房间定义](../Script/watch/rooms.ts) · [移动与蹲伏判定](../Script/watch/play.ts)

| 操作 | 键鼠 | 手柄（通用 / KTR） | 触屏 |
| :--- | :--- | :--- | :--- |
| 横移与纵深 | `A / D` 横移，`W / S` 走纵深，或用方向键 | 左摇杆 / 十字键四向移动 | 左侧虚拟摇杆四向移动 |
| 轻步慢走 | 按住 `Shift` | 按住 `LT / LB` | 横移时轻推内圈，或点「轻步」切换 |
| 蹲伏隐蔽 | 按住 `C` 或左右 `Ctrl` | `B`（操控设置可选按住 / 切换） | 「蹲伏」开关（离开低拱后可点跳跃起身起跳） |
| 跳跃攀爬 | `Space` | `A` | 「跳跃」钮 |
| 交互 / 拉车 | `E`，城外右柄按住 `E + D` | `Y / RB` 握柄并向右移动 | 情境交互钮（点按锁柄后向右推摇杆拉车） |
| 空村投瓶 | 按住 `F` + 鼠标 + 松手；**右键取消** | 按住 `RT / X` + 右摇杆调落点（左摇杆锁定防误移）+ 松手；**`B` 取消** | 按住「投瓶」拖向砖地松手；**拖回取消圈放弃** |

## 三、3:2 / 4:3 掌机屏与多比例视口细节

- **镜头横向视野补偿（`Script/watch/fe/camera.ts`）**：16:9 及更宽屏幕保持 `aspectComp = 1.0` 零变化；在 `1620×1080`（3:2）与 `1280×960`（4:3）下保守补偿缩放（下限 `0.82`），避免枪战房间横向视野被截窄，同时保持 `worldToScreen` / `screenToWorld` 严格互逆与风台双锚点锁定不变。
- **Web 触鼠共用**：触屏按下期间及抬起后 250 ms 内抑制合成鼠标事件，避免摇杆触摸误触开火。[Web 输入驱动](../Script/watch/targets/web/index.ts) · [触控路由](../Script/watch/input/touch_core.ts)

## 四、团队真机冒烟验收清单

1. 分别从发行包或 Dora 源码项目启动，确认品牌序幕后进入标题，并用该目标支持的输入跳过序幕。
2. 在「执器要诀」核对上表页数与键位。Windows 用键鼠、Android 手机用触屏完成菜单选择；Web 逐一切换三种输入，检查锁定偏好在重启后保留。
3. Android 手机与 Web 触屏分别检查横屏浮钮、竖屏上方舞台与下方操控台。独立 Android APK 另验标题退出与双击系统返回键退出。
4. KTR 横屏验证手柄与触屏切换、九宫格摇杆斜连与手指划线、`Back + Start` 热键避让。用小满在城外分别测试上下走纵深、`B` 蹲伏、触屏蹲伏开关，并在空村测试 `B` 取消投瓶。
