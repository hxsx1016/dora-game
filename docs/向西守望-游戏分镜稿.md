# 《向西守望》游戏分镜稿

本稿供关卡、镜头、动画、音效与玩法联调使用。秒数是首轮样片剪辑值。「可玩」镜头的长度由玩家决定。故事从明初温州宁村所开始，两条线都以北塔为终点，两线分别按约 90 分钟调时。

## 序章与送别

各镜的插入时机、玩家交权、声画节拍和样片交付顺序见[动画插入与演出规划](向西守望-动画插入与演出规划.md)。

| 镜号与触发 | 画面与声音 | 玩家控制 |
| --- | --- | --- |
| P01 开场，4 秒 | 黑场先听到父亲叫「小满」。第一人称睁眼，床帐亮起，父亲的手扶住床沿。她坐起时，门缝恰好进入视线。 | 镜头落稳即还移动。 |
| P02 走到门口，2 秒接可玩 | 镜头停在门槛内，墙上两道人影被一道长影截断。一只碗滚到小满脚旁。玩家回身时，厨柜门还在晃。 | 随碗停开始限时逃柜。入柜时红晕收尽，柜外脚步渐远。 |
| P03 周戍靠柜，3 秒 | 柜缝里露出一只小手。周戍用袖口擦掉柜沿的碎瓷才递手进去，给补过一道浅线的袖口一个近景。 | 双通关档在靠柜前可绕进井院。小满握手后交回双人护送。 |
| P04 井庭至军粮棚，可玩 | 兄妹从兵房巷井庭贴墙望向十字街，见街口交战，退回布行。镜头随小满的目光压低，露出窗板下沿、石槽磨痕，再回到两人都在画内的侧视距离。 | 玩家决定何时放板、推车、接回同伴。 |
| P05 绞盘至门缝，4 秒接可玩 | 从门柱后望出去，抬起的城门下露出护城河的水光。小满拉住有补线的袖口，周戍隔着布轻轻捏她的手，说「数到一百」。门落下前最后看到的是那截袖子。 | 守门的威胁留在城内。小满过门后锁存周戍血量，风台进入安全等待。 |

## 风台的剪辑与分线

故事里小满数了一百下。实机先试 **24 秒**，沿用 60 拍时钟的 1440 拍。跳过的数字通过声音剪辑交代，背景依据同一个归一化进度连续渐变。小满的脚和门槛在画面中保持对齐。

| 镜号与实机时间 | 构图与声音 | 交互 |
| --- | --- | --- |
| G01，0–6 秒 | 平视门下，手还维持攥袖的形状。轻数「一、二、三」，一道光擦过门框，显出第一道侧面。 | 镜头只跟呼吸轻移。 |
| G02，6–18 秒 | 同机位留住她的轮廓。叠过风声与「三十七」「七十二」，城墙在雾里显出厚度，栈台木板有了前后遮挡。 | 两线共用风台与海声。小满身边只有风、浪与自己的呼吸。 |
| G03，18–24 秒 | 她睁眼，数「九十八、九十九……一百」。最后一个音落下时，低模风台的投影已完整，人物仍为二维。 | 在末拍按已锁定的路线进入下镜。 |
| G04 女主线，可玩 | 保持宽景。门边空着，小满用那只攥过袖子的手收紧针套。风吹动远处车柄上的红布。 | 等玩家重新按方向键，她才走向栈台。 |
| G05 男主线，等待后约 4 秒 | 城外安静，侧墙上传来熟悉的两下轻叩。小满抬手。玩家按住交互，补过浅线的袖口先伸进画面，她抓住它。顺两人的手臂抬镜，回到序章像素风，露出蹲在她身边的周戍。他把袖口往回抽一点，让她握住自己的手，说 **「我们走吧。」** | 数完后长按现有交互键，首调 0.6 秒。袖口随按住进入画面，够时只触发一次出场与牵手。可松开再试，待机一直安全。 |
| G06 男主线，可玩 | 侧向跟拍，兄妹牵着手过一段平路，只听两种步幅。到高石阶时周戍才蹲下，小满自己攀到他背上。她问「去哪儿？」「北塔。你看，灯还亮着。」 | 握稳后交回移动。上背发生在下一段入口，随后接护送试炼。 |

## 分支、结局与井底尾声

| 镜号与触发 | 镜头、声音与交权 |
| --- | --- |
| F01 栈台／空村，可玩 | 小满抓到车柄红布时，插半秒家里人替她缝布的手，再回到同一握姿。桌下机位只拍得见拾荒者的鞋底。砖面响一声，铁盆响第二声余振，玩家自己选何时钻出。 |
| F02 林口／溪湾，可玩 | 枯枝响时先让小满和玩家一同停下来听。两条林路从不同高度来到溪湾，镜头先收进塔灯的水中倒影，抬头才见真灯。 |
| F03 北塔西窗，8 秒 | 玩家敲两下，门内隔一息回两声。守卒接过针套与纸条，写「小满」，笔尖悬在下一行。她问「朝西那盏灯，能留着吗？」守卒把灯端走，留白仍在画面里。 |
| M01 初次换弹，可玩 | 固定侧视把兄妹与远处威胁放进同一画面。小满从哥哥肩后探手时世界变慢，镜头贴近手与线盘。玩家连入纹样时它才发声，退出线盘时同一声音回到正常速度。 |
| M02 粮棚工台，可玩 | 周戍放下小满，她把一路捡来的材料一件件排在桌边。制成时由她把物件递还给哥哥，接回进工台前的全身景。 |
| M03 北塔值夜室，约 8 秒接可玩 | 小满在塔门上轻叩两下，里面回叩两声。守卒推开门，玩家牵她跨过门槛。西窗灯下，守卒摊开收籍问姓名，小满说自己的，周戍亲口答第二个。她终于把针套解下来放在桌上，两只手端碗。写满的两行与碗沿一同入画，落团圆结局。 |
| E01 双通关后的井院，可玩 | 从寻柜镜头的另一侧循滴水声入后院。玩家俯身时，井里白灯的倒影恰与指南针玻璃重叠。拾起穿梭器，匹配切到现代展柜玻璃上的同一点光。 |
| E02 现代抗日主题博物馆，可玩接 4 秒 | 镜头随周戍安静走过展厅。走到西窗，让玩家转动那盏灯。两声轻叩起于展厅，落回柜板，周戍伸手时是同一截袖口。交还寻柜任务。 |
