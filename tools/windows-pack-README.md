# 《向西守望》Windows x64 便携游玩包

> 明初温州宁村所 · 双线叙事 2.5D 侧视枪战 + 3D/2D 潜行冒险游戏
> 2026 开源游戏开发大赛（OSGJ）参赛作品 · 基于开源引擎 Dora SSR v1.10.2

## 一、快速启动（免安装、绿色便携）

1. **完整解压**本 ZIP 到任意本地目录（支持中文与空格路径；请勿在压缩包预览窗口中直接双击运行）。
2. 双击根目录 **`WestwardWatch.exe`** 即可直接启动游戏，无需任何批处理脚本或环境配置。
3. **版本选择说明**：
   - **标准版（`windows-x64.zip`）**：Direct3D 12 渲染，推荐绝大多数 Windows 10/11 电脑使用；
   - **兼容版（`windows-x64-opengl.zip`）**：OpenGL 渲染，若老旧显卡或虚拟机提示 Direct3D 12 初始化失败请改用此版本。

## 二、基础操作（键鼠）

| 按键 | 功能 |
| --- | --- |
| `W / A / S / D` 或方向键 | 移动 / 潜行（菜单页上下选择） |
| 鼠标 + 左键 | 周戍瞄准与发射火铳 / 点击菜单项 |
| 按住 `Shift` | 周戍贴靠掩体 / 小满轻步慢走 |
| `Space` | 周戍翻滚翻越 / 小满跳跃攀爬 |
| 按住 `S` / `Ctrl` | 小满蹲伏隐蔽与穿低拱 |
| `E` | 交互（递物、两下轻敲安抚、推拉板车、拾瓶、敲门、看井、暗渠回应） |
| `Q` | 男主护送段手动开启 3×3 慢时连线换弹（亦可点击/拖拽格点） |
| `1 / 2 / 3` | 护送段三选一本领 |
| `F`（按住瞄准→松开 / 右键取消） | 小满投瓶引开拾荒者 |
| `T` | 双通关后切换彩蛋武器「时间穿梭器」 |
| `R` | 重试当前检查点 |
| `M` | 一键静音 / 取消静音（自动保存） |
| `Esc` | 暂停菜单（存取档案、操作说明、按键辅助、游戏设置、切换全屏、返回标题或退出游戏） |
| `F11` 或 `Alt + Enter` | 全屏 / 窗口模式快速切换（自动保存） |

> 建议游玩时切换为英文输入法以避免输入法候选框抢占 `WASD` 按键。标题页与暂停菜单均提供「游戏设置」（四通道音量、全屏/窗口与按键辅助，全部自动保存）。源代码遵循 **Apache-2.0** 协议（见 `LICENSE`）。

## 三、便携存档与多槽位目录

本游戏默认以**纯绿色便携模式**运行，所有存档与配置均保存在游戏根目录的 `saves/` 文件夹内，整包拷贝到 U 盘或换电脑即可无缝续玩：

```text
WestwardWatch/
├── WestwardWatch.exe     # 游戏主入口（直接双击启动）
├── saves/                # 全部玩家存档与配置（整包可迁移）
│   ├── profile.sav       # 跨周目全局档案（双结局通关、神器、博物馆进度）
│   ├── autosave.sav      # 自动存档（切房、暂停、切后台及关键进度变更自动保存）
│   ├── slots/            # 三个独立手动存档槽位（slot_1.sav ~ slot_3.sav）
│   ├── settings.ini      # 个人设置（音量、静音、全屏/窗口尺寸、按键辅助）
│   ├── backups/          # 自动回滚备份（.prev）与异常档案隔离件
│   └── logs/             # 启动异常时自动导出的诊断日志（crash.log）
├── runtime/              # 引擎运行时、脚本与游戏素材（请勿手动删除或拆散）
├── LICENSE               # Apache-2.0 开源许可
└── README.md             # 本说明文档
```

- **多槽位存取**：可在标题页「读取存档」或局内暂停菜单「存取档案」中管理自动存档与 3 个独立槽位（含章节、路线、血量、游玩时长与保存时间，覆盖与删除均有二次确认）。
- **旧版存档平滑迁移**：若此前玩过旧版便携包（存档位于 `save/` 或 `%APPDATA%`），首次启动新版时会自动将旧档**复制**迁移至 `saves/`（不删除旧文件）。
- **只读目录自动兜底**：若将游戏解压到无写权限目录（如 `C:\Program Files\`），游戏会自动回退写入用户目录并在标题页给出提示，避免丢失进度。
- **建议正常退出**：请优先通过标题页或暂停菜单的「退出游戏」收尾落盘；局内虽已在切房、关键节点与定时自动保存，直接强杀进程或点击窗口关闭按钮仍可能丢失最近数秒内的未结算操作。

## 四、问题反馈

如遇到启动、显示、音频或交互问题，请反馈时附带：Windows 版本、显示器分辨率与缩放比例、`runtime/VERSION.txt` 内容、`saves/logs/` 下的日志（如有）以及复现步骤。
