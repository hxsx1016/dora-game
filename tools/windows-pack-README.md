# 《向西守望》Windows x64 便携游玩包

> 明初温州宁村所 · 双线叙事 2.5D 侧视枪战 + 2D 潜行平台游戏
> 2026 开源游戏开发大赛（OSGJ）参赛作品 · 基于开源引擎 Dora SSR v1.10.2

## 一、快速启动（免安装、免配置环境）

1. **完整解压**本 ZIP 到任意本地目录（支持中文路径，请勿直接在压缩包预览窗口中双击运行）。
2. 双击 **`WestwardWatch.exe`** 或 **`启动-向西守望.cmd`** 即可直接进入游戏标题页。
3. **版本选择说明**：
   - **标准版（`windows-x64.zip`）**：使用 Direct3D 12 渲染，推荐绝大多数 Windows 10/11 电脑使用；
   - **兼容版（`windows-x64-opengl.zip`）**：使用 OpenGL 渲染，若老旧显卡或虚拟机弹出 Direct3D 12 初始化失败提示，请改用此版本。

## 二、基础操作

| 按键 | 功能 |
| --- | --- |
| `W / A / S / D` 或方向键 | 移动 / 潜行（菜单页上下选择） |
| 鼠标 + 左键 | 周戍瞄准与发射火铳 / 点击菜单项 |
| 按住 `Shift` | 周戍贴靠掩体 / 小满轻步慢走 |
| `Space` | 周戍翻滚翻越 / 小满跳跃攀爬 |
| 按住 `S` / `Ctrl` | 小满蹲伏隐蔽与穿低拱 |
| `E` | 交互（递物、两下轻敲安抚、推拉板车、拾瓶、敲门、看井、暗渠回应） |
| `Q` | 男主护送段手动开启 3×3 慢时连线换弹（亦可点击/拖拽格点） |
| `1 / 2 / 3` | 护送段 / 试炼三选一本领 |
| `F`（按住瞄准→松开 / 右键取消） | 小满投瓶引开拾荒者 |
| `T` | 双通关后切换彩蛋武器「时间穿梭器」 |
| `R` | 重试当前检查点 |
| `Esc` | 暂停菜单（可查阅三模操作说明、开关按键辅助、调节操控设置、切换全屏、返回标题或退出游戏） |
| `F11` 或 `Alt + Enter` | 全屏 / 窗口模式快速切换 |

> 本作全平台原生支持**键鼠 / 手柄（Xbox & Nintendo 确认布局）/ 触屏**自动热切；默认采用低引导探索，若希望获得就近按键提示，可随时按 `Esc` 在暂停菜单中开启「按键辅助」。源代码遵循 **Apache-2.0** 协议（见包内 `LICENSE`）。

## 三、存档与绿色便携模式

- **默认存档位置**：为防止覆写升级时丢失进度以及避免只读目录权限问题，跨局通关档案默认隔离保存在：
  `%APPDATA%\IppClub\DoraGame-7a9d4e21c8f34b6ea1d05c83b2f69e41\watch-save\archive.txt`
- **纯绿色便携存档（可选）**：如需随 U 盘携带存档或一键重置全新档案，只需在 `WestwardWatch.exe` 同级目录新建一个空的 `save` 文件夹，游戏会自动将存档读写定向至该 `save/` 目录。
- **正常退出**：可通过标题页或暂停菜单的「退出游戏」安全落盘并退出，直接关闭窗口也会自动保存待落盘进度。

## 四、包内结构

| 路径 | 用途 |
| --- | --- |
| `WestwardWatch.exe` | Dora SSR v1.10.2 Windows x64 独立游戏运行时 |
| `WestwardWatch.ico` | 《向西守望》Windows 多尺寸应用图标（可用于桌面快捷方式或自定义图标） |
| `dora-game-id` | 独立游戏标识（锚定资源路径、隔离单实例锁与存档目录） |
| `启动-向西守望.cmd` | 中文路径兼容启动脚本 |
| `Script/init.lua`、`Script/main.lua`、`Script/watch/` | 发行启动引导、游戏入口、玩法与水墨/低模前端 Lua 模块 |
| `Script/Lib/`、`Font/`、`Shader/`、`Image/` | 精简后的 Dora SSR 最小运行时依赖 |
| `assets/` | 场景、角色、水墨 UI、开源中文字体（霞鹜新致宋 / 龙藏体）及全部分轨 WAV 音频 |
| `VERSION.txt`、`SHA256SUMS`、`LICENSES` | 版本元数据、文件校验清单与开源许可声明 |
